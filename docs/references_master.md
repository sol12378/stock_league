# 参考文献マスター(BEYOND BUFFETT 全フェーズ網羅版)

作成日: 2026-07-18
目的: 本プロジェクトでこれまでに使用・参照した文献を一箇所に集約し、各成果物(STOCKリーグ提出版・青学懸賞論文版・phase別詳細解説)の参考文献欄の**正典**とする。

**書式の方針**(docs/explain_docs および `outputs/beyond_buffett_fable_loop_final/phase7_final_report/final_references.md` の様式を踏襲):
- 英語文献を先、日本語文献を後。英語は著者姓のアルファベット順、日本語は五十音順。
- 定期刊行物は「著者名 (刊行年) 論文タイトル. *雑誌名*, 巻(号), pp.ページ」。書籍はタイトルをイタリック。
- インターネット文献は「著者名「タイトル」サイト名, URL (最終確認日)」。
- 各エントリ末尾の【 】は本プロジェクト内の**用途**(どのPhase・式・成果物で使ったか)。
- 「掲載セット」節で、成果物ごとにどの文献を載せるかを管理する(本文引用⇔文献の双方向対応が要件)。

## 9. 運用メモ

1. 新しい文献を使うときは、まず本ファイルに追記し(用途タグつき)、次に該当成果物の掲載セットを更新する。
2. 成果物に文献を載せる前に「本文のどこで引用したか」を必ず対応表(§8 または各版の audit)に書く。逆も同じ。
3. 一次資料の引用文は原典で確認してから使う(§1 の3通は2026-07-18確認済み。確認方法: berkshirehathaway.com の原文)。
4. 書誌の正確性: 本ファイルの記載は `docs/phase2_references.md`・`final_references.md`・各texのReferencesから転記・統合したもの。表記ゆれはこのマスターの形を正とする。
