Stock League Screening Method

BEYOND BUFFETT
スクリーニングの考え方と式

「完成された堀」だけでなく、日本企業の資本効率改善、事業変革、AI時代の新しい産業基盤を評価するため、 財務・株価・テーマ性を統合したスコアで候補銘柄を選定した。

01 / Framework

基本思想

1

守る堀

収益性、キャッシュ創出力、安定性、競争地位から、既に強い事業基盤を持つ企業を評価する。

2

変わる堀

低PBR・低PER、ROE改善、配当、成長率から、資本効率改善や再評価余地を評価する。

3

生まれる堀

半導体、光通信、データセンター、電力、省人化、データ・ソフトウェアなど、将来の堀を評価する。

4

価格規律とリスク

良い企業を高値づかみしないため、PER・PBR・配当利回り、モメンタム、ボラティリティを加味する。

02 / Funnel

絞り込みの流れ

  1. 東証上場銘柄 3,649社を初期ユニバースに設定。
  2. 株価取得可能 終値が取得でき、価格が正の銘柄に限定。3,648社。
  3. 流動性条件 60日平均売買代金が2,000万円以上。2,560社。
  4. 投資適格性 財務安全性、継続収益力、営業CF、異常値、データ品質を確認。1,963社。
  5. スコア上位80社 Adjusted Beyond Buffett Scoreの上位80社を候補母集団にする。
  6. 最終20社 役割別スコアと分散制約で、20銘柄のポートフォリオ候補を選ぶ。

03 / Normalization

スコア化の前処理

外れ値処理

各指標は1%点から99%点の範囲にクリップし、極端な値の影響を抑えた。

winsorize(x) = clip(x, q01, q99)

標準化

指標間の単位差をなくすため、横断面のZスコアに変換した。

z(x) = (winsorize(x) - mean) / std

割安指標の反転

PER・PBRは低いほど評価されるため、逆数を標準化して使った。

cheapness(PER) = z(1 / PER)

04 / Score Formula

主要スコアの式

Moat Score: 既存の堀

収益力、キャッシュ創出力、安定性、競争地位を統合する。

Moat = 0.35 Profitability + 0.25 CashGeneration + 0.20 Stability + 0.20 CompetitivePosition

Transformation Score: 変わる堀

低PBR・低PER、売上・営業利益の成長、配当利回りから、再評価余地と資本効率改善を測る。

Transformation = 0.35 z(1/PBR) + 0.20 z(1/PER) + 0.20 avg_z(RevenueGrowth, OperatingIncomeGrowth) + 0.15 z(DividendYield)

Future Moat Score: 生まれる堀

AIインフラ、無形資産投資、省人化、データ・ソフトウェア、信頼・セキュリティへの露出を評価する。

FutureMoat = 0.30 AIInfrastructure + 0.25 IntangibleAsset + 0.20 Automation + 0.15 DataSoftware + 0.10 TrustSecurity

Valuation Score: 価格規律

利益、純資産、株主還元の3面から、価格の妥当性を確認する。

Valuation = 0.50 z(1/PER) + 0.35 z(1/PBR) + 0.15 z(DividendYield)

Beyond Buffett Score

守る堀、変わる堀、生まれる堀を中核にし、最後に価格規律を加える。

BB = 0.30 Moat + 0.25 Transformation + 0.30 FutureMoat + 0.15 Valuation

Adjusted Beyond Buffett Score

直近12か月から直近1か月を除いたモメンタムを加点し、ボラティリティと最大ドローダウンを減点する。

AdjustedBB = BB + 0.10 Momentum - 0.10 Risk

05 / Deep Dive

式ごとの説明変数と有効性

前処理: winsorize、Zスコア、逆数化

異なる単位の財務指標を同じ土俵で比較し、極端な外れ値に順位全体が支配されないようにした。

winsorize(x) = clip(x, q01, q99)

1%点未満は1%点に、99%点超は99%点に丸める。

z(x) = (winsorize(x) - mean) / std

各銘柄が母集団平均との差でどれだけ優れているかを表す。

cheapness(PER, PBR) = z(1 / PER), z(1 / PBR)

PER・PBRは低いほど割安なので、逆数にしてから標準化する。

なぜ有効か

  • 単位差を消す: ROE、売買代金、配当利回りなどを重み付きで足し合わせられる。
  • 外れ値を抑える: 一時的な赤字や会計上の特殊要因による極端値の影響を小さくする。
  • 横断比較に向く: 同じ時点の日本株全体の中で、相対的に強い企業を見つけられる。
レポート接続文 本分析では、各財務指標をそのまま足し合わせず、外れ値処理後にZスコア化した。これにより、単位の異なる指標を同一尺度で比較し、極端な一社にスコアが過度に左右されることを避けた。

投資適格性フィルター

スコア以前に、500万円の仮想ポートフォリオに組み入れる最低条件を満たすかを確認した。

条件 説明変数 狙い
株価取得可能close > 0実際に購入価格を置ける銘柄に限定する。
流動性avg_trading_value_60d >= 20,000,000円売買代金が小さすぎる銘柄を避ける。
財務安全性equity_ratio、total_assets、equity債務超過や自己資本が薄い企業を除く。
継続収益力operating_income、ordinary_income、net_income赤字が続く企業を機械的に高評価しない。
営業CFoperating_cf、ocf_margin利益が現金化されているかを見る。
データ品質price_history_days、PER/PBR/ROE異常値スコア計算の信頼性を確保する。

なぜ有効か

  • 投資不能銘柄を除く: 株価や流動性が不足する銘柄は、理論上よく見えても実践的ではない。
  • バリュートラップを避ける: 低PER・低PBRでも、財務悪化や赤字継続がある場合は割安とは限らない。
  • 説明責任を高める: 除外理由を分類することで、恣意的な銘柄選定ではないことを示せる。
レポート接続文 第0段階では、スコアの高低ではなく投資対象としての最低条件を確認した。これは、単なるランキング作成ではなく、実際に500万円を配分する前提で、価格取得可能性、流動性、財務安全性、データ品質を満たす銘柄に分析対象を限定するためである。

Moat Score: 守る堀

既存事業の強さを、利益率、現金創出、株価安定性、競争地位から評価した。

Moat = 0.35 Profitability + 0.25 CashGeneration + 0.20 Stability + 0.20 CompetitivePosition
説明変数 主な元指標 意味
Profitabilityoperating_margin、roe、equity_ratio高い利益率と資本効率を継続できる力。
CashGenerationocf_margin会計上の利益が営業キャッシュフローに変わる力。
Stability-annual_volatility株価変動が相対的に小さく、事業評価が安定していること。
CompetitivePositionrd_ratio、operating_margin研究開発や利益率に表れる競争地位。

なぜ有効か

  • Buffett型の中核: 高収益・高キャッシュ創出企業は、景気変動時にも耐久力を持ちやすい。
  • 利益の質を見る: 営業CFを入れることで、見かけの利益だけでなく現金化能力を評価する。
  • ポートフォリオの土台: Future Moatの成長リスクを、既存Moat銘柄で支える設計にできる。
レポート接続文 Moat Scoreは、既に強い事業基盤を持つ企業を見つけるための指標である。収益性だけでなく営業キャッシュフローと安定性を加えることで、一時的な利益ではなく、継続的に稼ぐ力を評価した。

Transformation Score: 変わる堀

日本株市場で重要な、低PBR是正、資本効率改善、事業改革、株主還元の余地を評価した。

Transformation = 0.35 z(1/PBR) + 0.20 z(1/PER) + 0.20 avg_z(RevenueGrowth, OperatingIncomeGrowth) + 0.15 z(DividendYield)
説明変数 意味 評価の方向
z(1/PBR)純資産対比の割安さ。PBRが低いほど高評価。
z(1/PER)利益対比の割安さ。PERが低いほど高評価。
RevenueGrowth売上成長。成長率が高いほど高評価。
OperatingIncomeGrowth営業利益成長。利益改善が強いほど高評価。
DividendYield株主還元。配当利回りが高いほど高評価。

なぜ有効か

  • 低PBR是正に対応: 日本企業では資本効率改善や株主還元強化が株価再評価につながりやすい。
  • 単なる割安を避ける: 成長率を入れることで、低PBRだが停滞している企業だけを拾うリスクを抑える。
  • 変化を買う: 現在の完成度よりも、資本政策や業績改善で評価が変わる余地を重視する。
レポート接続文 Transformation Scoreは、現在の優良企業だけでなく、資本効率改善によって市場評価が変わる企業を拾うための指標である。低PBR・低PERに成長率と配当利回りを組み合わせることで、割安さと変化の兆しを同時に評価した。

Future Moat Score: 生まれる堀

AI時代に新しく形成される産業基盤への接続度を、事業テーマと無形資産投資から評価した。

FutureMoat = 0.30 AIInfrastructure + 0.25 IntangibleAsset + 0.20 Automation + 0.15 DataSoftware + 0.10 TrustSecurity
説明変数 主な判定材料 意味
AIInfrastructure半導体、光通信、データセンター、電力、電子部品AI普及を支える物理インフラ。
IntangibleAssetrd_ratio研究開発など、将来競争力への投資。
Automationロボット、FA、センサー、精密機器、機械人手不足と省人化需要への対応力。
DataSoftwareソフトウェア、クラウド、SaaS、情報通信データ活用と業務デジタル化の基盤。
TrustSecurityセキュリティ、検査、品質、監査、保険AI・データ社会で重要になる信頼性の基盤。
半導体 光通信 データセンター 電力 省人化 ソフトウェア セキュリティ

なぜ有効か

  • 過去財務だけでは見えない: 将来の堀は、現在の利益率よりも産業構造の変化から生まれることがある。
  • AI時代の需要に接続: 半導体、通信、電力、データ基盤は、AI利用拡大のボトルネックになりやすい。
  • テーマ投資を定量化: キーワードと業種情報を使い、単なる主観ではなく再現可能な形でテーマ性を点数化する。
レポート接続文 Future Moat Scoreは、AI時代に新しく生まれる競争優位を捉えるための指標である。半導体、光通信、データセンター、電力、省人化、ソフトウェア、セキュリティといった領域への接続度を評価し、過去の財務指標だけでは見落としやすい将来の成長基盤を取り込んだ。

Valuation Score: 価格規律

良い企業や成長テーマを、高すぎる価格で買わないための制約として使った。

Valuation = 0.50 z(1/PER) + 0.35 z(1/PBR) + 0.15 z(DividendYield)
説明変数 意味 重みの理由
z(1/PER)利益に対して株価が割安か。現在の利益との対応を最も重視。
z(1/PBR)純資産に対して株価が割安か。日本株の低PBR是正テーマと接続。
z(DividendYield)株主還元の厚さ。下値耐性と資本政策の姿勢を補助的に評価。

なぜ有効か

  • 高値づかみを抑える: Future Moat銘柄は期待が先行しやすいため、価格規律を別に置く必要がある。
  • 利益と資産の両面を見る: PERだけでは資産価値、PBRだけでは収益力を見落とす。
  • 株主還元を加味: 配当利回りは、企業が株主へ利益を返す姿勢を反映する。
レポート接続文 Valuation Scoreは、投資テーマの魅力と購入価格を切り離して考えるために導入した。PER、PBR、配当利回りを用いることで、成長期待だけでなく、現在の利益・純資産・株主還元に対して妥当な価格かを確認した。

Momentum Score と Risk Score

市場が既に評価し始めている銘柄を加点しつつ、値動きが大きすぎる銘柄にはリスク控除を入れた。

Momentum = z(Return12M - Return1M)

直近12か月リターンから直近1か月リターンを除き、短期的な過熱を少し抑える。

Risk = avg_z(AnnualVolatility, Abs(MaxDrawdown))

年率ボラティリティと最大ドローダウンの大きさを平均する。

説明変数 意味
Return12M - Return1M短期急騰だけでなく、中期的な市場評価を捉える。
AnnualVolatility日次リターンの標準偏差を年率換算した値。
Abs(MaxDrawdown)過去期間でピークからどれだけ下落したか。

なぜ有効か

  • 市場の確認を使う: 財務やテーマが良くても、市場評価が全くついていない銘柄は時間がかかる可能性がある。
  • 短期過熱を抑える: 直近1か月を除くことで、急騰直後だけを拾うリスクを減らす。
  • 下落耐性を意識: ボラティリティとドローダウンを入れ、リターンだけを追う選定にしない。
レポート接続文 Momentum Scoreは、市場が企業価値の変化を認識し始めているかを見る補助指標である。一方、Risk Scoreはボラティリティと最大ドローダウンを用い、期待リターンだけでなく損失の大きさも選定に反映した。

Beyond Buffett Score と Adjusted Beyond Buffett Score

守る堀、変わる堀、生まれる堀、価格規律を統合し、最後に市場評価とリスクで補正した。

BB = 0.30 Moat + 0.25 Transformation + 0.30 FutureMoat + 0.15 Valuation AdjustedBB = BB + 0.10 Momentum - 0.10 Risk
構成要素 重み 役割
Moat30%既存の事業基盤と安定性。
Transformation25%日本株再評価と資本効率改善。
Future Moat30%AI時代の新しい成長基盤。
Valuation15%高値づかみを避ける価格規律。
Momentum+10%市場評価の確認。
Risk-10%価格変動と下落リスクの控除。

なぜ有効か

  • 一つの価値観に偏らない: 既存優良株、割安再評価株、未来成長株を同時に比較できる。
  • テーマと規律を両立: Future Moatを重視しつつ、ValuationとRiskで過度な期待先行を抑える。
  • 最終選定の母集団を作る: AdjustedBB上位80社を選ぶことで、定量的に優位な候補だけを次段階に進める。
レポート接続文 Beyond Buffett Scoreは、Buffett型の既存Moatに、日本株のTransformation MoatとAI時代のFuture Moatを加えた統合指標である。Adjusted Scoreでは、モメンタムを加点し、リスクを控除することで、成長期待と価格変動リスクのバランスを取った。

金融業の別処理

銀行、保険、証券は一般事業会社と財務構造が異なるため、同じ営業CF・自己資本比率基準を機械的に当てない。

一般事業会社で重視 金融業で重視
営業利益率、営業CF、自己資本比率ROE、純利益・経常利益の安定性
有利子負債倍率、OCFマージンPBR、PER、配当利回り
売上成長、営業利益成長資本効率、株主還元、業種内相対評価

なぜ有効か

  • 財務構造の違い: 金融業の負債や営業CFは、一般事業会社と同じ意味を持たない。
  • 不自然な除外を避ける: 機械的な自己資本比率や営業CF基準では、金融業が過度に不利になる。
  • 金融業に合う評価軸: ROE、PBR、利益安定性、株主還元は、金融銘柄の再評価余地を説明しやすい。
レポート接続文 金融業については、一般事業会社と同じ営業CFや負債倍率を用いると評価が歪むため、ROE、PBR、利益安定性、株主還元を中心に業種内で相対評価した。これにより、金融業を機械的に排除せず、Transformation Moatの観点から評価できるようにした。

07 / Final 20

最終20社の選び方

役割別の枠

  • 変わる堀: 6社
  • 生まれる堀: 7社
  • 守る堀: 5社
  • 分散・橋渡し枠: 2社

分散制約

  • 同一33業種は最大5社まで。
  • 金融業は最大3社まで。
  • 電力・ガスは最大3社まで。
  • 同一銘柄の重複採用は不可。

変わる堀の役割スコア

0.45 AdjustedBB + 0.25 Transformation + 0.20 Valuation + 0.10 Moat - 0.05 RiskPenalty

生まれる堀の役割スコア

0.45 AdjustedBB + 0.25 FutureMoat + 0.10 Moat + 0.05 Transformation - 0.04 RiskPenalty + themeBonus

守る堀の役割スコア

0.35 AdjustedBB + 0.35 Moat + 0.10 Transformation + 0.05 FutureMoat + 0.05 Valuation - 0.05 RiskPenalty + moatBonus

分散・橋渡し枠の役割スコア

0.45 AdjustedBB + 0.20 Moat + 0.15 Transformation + 0.10 FutureMoat + 0.10 Valuation - 0.05 RiskPenalty

役割別スコアを使う理由

AdjustedBB上位だけで20社を選ぶと、似た特徴の銘柄に偏りやすい。そこで、最終段階では役割ごとの目的に合わせて重みを変えた。

役割 重視する説明変数 選定上の意味
変わる堀AdjustedBB、Transformation、Valuation、Moat再評価余地があり、かつ価格面の説得力がある企業を選ぶ。
生まれる堀AdjustedBB、FutureMoat、Moat、Transformation、themeBonusAIインフラや省人化など、将来の堀に接続する企業を選ぶ。
守る堀AdjustedBB、Moat、Transformation、FutureMoat、moatBonusポートフォリオの安定性を支える既存優良企業を選ぶ。
分散・橋渡し枠AdjustedBB、Moat、Transformation、FutureMoat、Valuation特定テーマへの偏りを抑え、全体のバランスを整える。

なぜ有効か

  • 上位ランキング依存を避ける: スコア上位だけでは、モメンタムや特定業種に偏る可能性がある。
  • 投資仮説を形にする: 守る堀、変わる堀、生まれる堀を明示的に配分することで、戦略の意図が読み手に伝わる。
  • 分散を同時に満たす: 業種上限、金融業上限、電力・ガス上限を置き、テーマ集中と個別リスクを抑える。
レポート接続文 最終20社は、AdjustedBB上位80社をそのまま採用したものではない。ポートフォリオ全体が「守る堀」「変わる堀」「生まれる堀」の三層構造になるよう、役割別スコアと分散制約を用いて選定した。これにより、定量スコアの高さと投資ストーリーの一貫性を両立させた。
