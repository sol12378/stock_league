# 2倍株調査・完全実行計画

策定日: 2026-08-18  
対象市場: 日本株、原則として東証内国普通株  
主要評価時点: 各年6月末  
主目的: 1年、3年、5年で2倍へ到達する確率と、到達後も上昇を維持する確率を、完全な時点整合データで予測・説明する。

## 1. 調査の最終成果

本調査では、単一の「2倍候補ランキング」ではなく、次の6成果物を作る。

1. **短期到達モデル**: 1年以内に一度でも2倍になる確率
2. **持続モデル**: 1年後、3年後、5年後に2倍以上を維持する確率
3. **到達時間モデル**: 2倍までの日数と、その前に被る最大下落
4. **失敗モデル**: 半値、上場廃止、大幅希薄化、会計問題等の確率
5. **達成経路モデル**: 業績変化、割安是正、資本政策、大株主、再編・TOB、投機型の分類
6. **説明可能な銘柄カルテ**: 候補ごとに、根拠、反証、触媒、主要リスク、類似過去事例を提示

最終的な投資対象は、`2倍確率`だけでなく、`2倍確率 × 持続確率 × 損失回避確率 × 流動性`で順位付けする。

## 2. 絶対原則

### 2.1 ポイント・イン・タイム

- 特徴量は、その時点までに公表された情報だけで構成する。
- EDINETは`submitDateTime`を可用時刻とする。
- 後日の訂正書類で過去の特徴量を上書きしない。
- 訂正前と訂正後を別原本として残し、その時点で利用可能だった最新版を親子関係から復元する。
- 現在のEDINETコードリスト、上場区分、会社名、業種を過去へ遡及適用しない。
- 文章モデルの語彙・平均・埋込み・分類器も、学習時点より後の文章で学習しない。
- 欠損値を後年の比較列、後年有報、現在の会社情報で補完しない。

### 2.2 売買可能時刻

各年6月30日23:59 JSTまでの開示を使う場合、基準価格は翌取引日の始値又はVWAPとする。6月30日終値を基準価格にする場合は、同日立会終了後の開示を特徴量から除外する。

本計画の標準仕様は次とする。

- 情報カットオフ: 各年6月30日23:59:59 JST
- エントリー: 7月最初の取引日の調整前始値
- 補助評価: 同日のVWAP又は終値
- エグジット: 各ホライズン最終取引日の調整後終値
- 期間中到達: 調整後高値ではなく、まず調整後終値で判定し、高値判定を感度分析とする

### 2.3 原本優先

Bronze層では変換・再圧縮・ファイル名変更を行わず、APIレスポンスのバイト列をそのまま保存する。全ファイルへSHA-256、バイト数、取得日時、HTTP Content-Type、API type、docIDを付与する。

## 3. 調査対象ユニバース

### 3.1 主ユニバース

- 各基準日時点で東証に上場していた内国普通株
- プライム、スタンダード、グロース及び旧市場区分
- 期間中に上場廃止した銘柄を含む
- コード変更、合併、株式移転、持株会社化を企業イベントとして接続

### 3.2 分離する証券

- REIT、ETF、ETN、インフラファンド
- 優先株、種類株
- 外国株、重複上場
- 新規上場後の履歴が短い銘柄
- 整理・監理銘柄

これらは除外ではなく別ユニバースとして保存し、主モデルへ混ぜない。

### 3.3 投資可能性フィルター

モデル学習前に除外せず、まず全銘柄の結果を保存する。その後、運用モデルとして次を適用する。

- 基準株価100円以上
- 時価総額10億円以上
- 60日平均売買代金500万円以上
- 20日中10日以上の取引実績
- 売買停止・上場廃止予定を別フラグ化

閾値は固定値だけでなく、インフレ・市場規模を考慮した年次分位でも感度分析する。

## 4. ラベル設計

### 4.1 基本ラベル

| ラベル | 定義 |
|---|---|
| `hit_2x_1y` | 1年以内の調整後終値がエントリー価格の2倍以上 |
| `end_2x_1y` | 1年後の調整後終値が2倍以上 |
| `hit_2x_3y` | 3年以内に一度でも2倍 |
| `end_2x_3y` | 3年後に2倍以上を維持 |
| `hit_2x_5y` | 5年以内に一度でも2倍 |
| `end_2x_5y` | 5年後に2倍以上を維持 |
| `days_to_2x` | 初回2倍到達までの取引日数 |
| `max_drawdown_before_2x` | 到達前の最大下落率 |
| `end_return` | ホライズン期末リターン |
| `permanent_loss` | 期末-50%以下又は価値毀損型上場廃止 |

### 4.2 コーポレートアクション

- 株式分割・併合は価格と株式数を同一基準へ調整する。
- 配当込みリターンと価格リターンを併記する。
- TOB、MBO、株式交換、完全子会社化は別ラベルを立てる。
- 上場廃止価格、最終売買日、対価株式・現金を可能な限り反映する。
- 通常増資は調整係数で消さず、希薄化イベントとして特徴量へ残す。

### 4.3 達成経路サブタイプ

1. 業績加速型
2. 赤字黒字転換型
3. 低評価是正・資産価値型
4. 自己株買い・増配・資本効率改善型
5. 大量保有・アクティビスト型
6. 事業再編・M&A型
7. TOB・MBO型
8. セクター／マクロ再評価型
9. 高ボラティリティ・テーマ型
10. 複合型

サブタイプはルールによる仮ラベルと人手検証標本を作り、最終的にマルチラベル分類する。

## 5. データアーキテクチャ

### 5.1 Bronze: 原本

- EDINET日別書類一覧JSON
- type 1 本文・監査ZIP
- type 2 PDF
- type 3 代替書面・添付ZIP
- type 4 英文ZIP
- type 5 XBRL変換CSV ZIP
- EDINETコード・ファンドコード原本
- 様式コード、API仕様、各年タクソノミ・要素リスト
- 株価・出来高・コーポレートアクションの取得元原本
- 歴史的上場銘柄一覧、上場廃止一覧

### 5.2 Silver: 正規化

| テーブル | 粒度 | 主な内容 |
|---|---|---|
| `documents` | docID | 提出メタデータ、親子、状態、全フラグ |
| `facts_long` | docID×concept×context×unit | 全XBRLファクト |
| `text_blocks` | docID×concept | MD&A、リスク、KAM等 |
| `capital_events` | 会社×時刻×イベント | 発行、潜在株、買戻し、消却、配当 |
| `ownership_events` | 発行会社×提出者×時刻 | 大量保有、変更、共同保有 |
| `corporate_events` | 会社×時刻 | M&A、TOB、主要株主・代表者異動等 |
| `audit_control` | 会社×期間 | 監査意見、KAM、内部統制 |
| `segments` | 会社×期間×セグメント | 売上、利益、資産、地域、顧客 |
| `governance` | 会社×期間×人物／保有者 | 役員、大株主、政策保有 |
| `entity_history` | EDINETコード×有効期間 | 名称、上場、業種、決算期 |
| `security_history` | 証券ID×日付 | コード、価格、株式数、調整係数 |

### 5.3 Gold: 学習スナップショット

1行を`security_id × anchor_date`とする。全列に次を持たせる。

- `available_at`: 情報が利用可能になった時刻
- `source_doc_id`: 原本docID
- `source_period_end`: 対象決算期
- `taxonomy_version`
- `consolidation_scope`
- `restatement_state`
- `feature_missing_reason`

値だけでなく出所・時点を保持し、任意の特徴量から原本へ逆引き可能にする。

### 9.2 3年・5年モデル

- ラベル期間が重なるため、通常のランダムCVを禁止する。
- 3年モデルは最低3年、5年モデルは最低5年のpurge／embargoを置く。
- 2021年以前の基準コホートを主学習とし、2022～2023年を途中経過評価に使う。
- 完結していないラベルは打切りとして生存時間モデルで扱い、負例にしない。

### 9.3 レジーム耐性

- 資源高・資源安

## 11. 実験順序

### Experiment 0: 再現

既存モデルを新しい時点スナップショット上で完全再現し、価格・株式数・ラベル差を照合する。

### Experiment 1: データ品質

訂正、取下げ、提出遅延、監査、内部統制だけを追加する。目的はAUC上昇より偽陽性・大損失削減。

### Experiment 2: 1株価値

増資、潜在株、自己株買い、消却、配当を追加する。希薄化調整後の1株価値成長を検証する。

### Experiment 3: 業績鮮度

半期・旧四半期、セグメント、受注を追加する。利益転換・成長加速度の寄与を検証する。

### Experiment 4: 触媒

大量保有、M&A、TOB、主要株主異動を追加する。通常成長型とイベント型を分離する。

### Experiment 5: 長期品質

大株主・役員、政策保有株、人的資本、増分ROIC、減損・のれんを追加する。

### Experiment 6: 文章

MD&A、リスク、KAMの時系列変化を追加する。文章単独と数値融合を比較する。

### Experiment 7: 経路別モデル

達成経路ごとに専門モデルを学習し、総合確率へ統合する。

## 12. 合格基準

モデル更新は次の全条件を満たした場合だけ採用する。

- 完全ホールドアウトの上位5%リフトが基準モデルを上回る
- 2025年だけでなく複数検証年の中央値が改善
- PR-AUC、Brier scoreの少なくとも一方が改善
- 最大損失・永久損失率が悪化しない
- TOB除外後にも選別力が残る
- 単一業種・単一イベントへの依存が説明可能
- 特徴量の原本・時点・変換を追跡可能
- 再実行で同一結果を生成できる

目標値は予測ではなく研究上のゲートとして、上位5%の1年期末2倍率を現行10.69%から13%以上、期間中2倍率を19.50%から23%以上へ引き上げる。ただし一年度だけで達成した場合は採用しない。

## 15. 取得容量と継続運用

全5形式は、type 2 PDFとtype 5 CSVがtype 1の内容と重複するため、保存容量が大きい。ただし依頼どおり全形式を対象にする。次の順で取得する。

1. type 1 本文・監査
2. type 3 添付、type 4 英文
3. type 2 PDF
4. type 5 CSV

全日別一覧の走査後、各形式200件以上の実測平均・上位分位から総容量を推定する。内蔵ストレージで完了不能なら、原本を削除せず外部ストレージへアーカイブルートを移し、同じSQLiteマニフェストで再開する。
