# 入賞レポートとの相違点分析と修正方針（STOCK League Gap Analysis）

参照した入賞作：25_01「EXPERTNER」（東大）・25_04「同族企業」・26_01「OUTLIER — グロースの夜明け」（東大）。
比較対象：現行の `contest_report_30pages`（初学者向け説明論文）および `final_revision`（青学学生懸賞論文様式）。

## 0. 根本診断 ― 「ジャンル」が違う

現行レポートが入賞作と「何もかも違う」最大の原因は、個々の体裁ではなく**文書のジャンルそのもの**にある。

- **入賞作**＝「チームが紡ぐ投資テーマの物語」。造語コンセプト（EXPERTNER／OUTLIER）を主人公に、序論の引用（26_01はジョブズの "Think Different"）から企業のエピソード（ファストリ・任天堂）へ、そしてスクリーニングは**コンセプトの要件を確かめる旅**として展開される。式や表はその物語の道具。チーム名・実名・指導教員・写真が前面に出る。
- **現行**＝「匿名の学術論文／教科書」。直近2回の指示（青学学生懸賞論文様式→初学者向け説明論文）を忠実に実装した結果、**方法論が主人公**（守破離のPhase・22本の式・8項目テンプレ・監査）になり、物語・チーム・ビジュアルが消えた。

つまり現行2文書は「指示された別ジャンルの完成品」であって、STOCKリーグ提出物としては**土台から組み直しが必要**。ただし全面的な作り直しではない——本セッション前半で作った **phase7版（STOCKリーグ様式・ティールバナー・19頁）が正しい骨格**を既に持っており、そこに今回の実データ・説明力を移植するのが最短路。

## 2. 現行が持つ「入賞作にない強み」（捨てずに再配置するもの）

1. **監査可能性**：全選定が正典CSV・除外862社リスト・アブレーション16通りで反証可能。入賞作は判定基準は示すが再現データまでは付けない。
2. **誠実性**：in-sample明示・直近1年IR負の開示・設計式と実装式の区別。審査で「やりました感」ではなく研究倫理として効く差別化要素。
3. **式ボックスの品質**：OMMLネイティブのv11型ボックスは入賞作の式提示より美しい。
4. **実データの通し計算**（9470で12ステップ）：どの入賞作にもない独自の説得装置。付録として強い。
これらは**主役から脇役へ**降ろし、物語の裏づけとして数カ所で効かせる。

## 3. 修正方針（優先順）

**方針：第4系統「STOCKリーグ提出版（contest edition）」を新設。** 土台は phase7版（構成・ティールバナー・銘柄紹介表・インタビュー枠が既に入賞作準拠）。そこへ explanatory 版の平易な語彙と実データを移植する。青学様式（final_revision）と詳細解説版（explanatory）は別目的の成果物としてそのまま保持。

| 優先 | 修正点 | 具体策 |
|---|---|---|
| P1 | **物語への転換** | 序論を「引用→逸話→我々の問い」で書き直す。引用候補＝バフェットの堀の言葉。逸話は**ポートフォリオ内の実話**を使う：5803フジクラ（100年電線企業がAIデータセンター光配線で再評価＝「生まれる堀」の生き証人）、低PBR企業の東証改革（「変わる堀」）。造語コンセプトは既にある——**「三世代の堀」と守破離**を EXPERTNER/OUTLIER 級の看板として前面に |
| P2 | **章構成を入賞作標準へ** | 基礎学習（記入枠）→要旨→目次（頁番号）→Ⅰ背景・投資テーマ決定→Ⅱスクリーニング（第1:守=完成した堀／第2:破=候補の拡張／第3:離=変わる堀・生まれる堀）→Ⅲポートフォリオ決定・銘柄紹介・パフォーマンス→Ⅳインタビュー→Ⅴ学んだこと→参考文献 |
| P3 | **式のダイエット** | 本文の式ボックスは6〜7本（B/M・GP・Trans実装形・Emerging・Evidence・配分・単元株）。各スクリーニングは入賞作型の**判定基準表**（観点／使うデータ／基準／通過社数）で語り、8項目の残り（変数表・数値例）は詳細解説版へ参照。用語は初出で一言定義（用語集の独立章は廃止し脚注化） |
| P4 | **語り口の全面書き換え** | 「私たちは」主語・短文・各章末に「ここまでで分かったこと」1行。検証章も「私たちは成績を誇る代わりに、壊れにくさを確かめた」という物語として提示（誠実性を主体的な選択として語る） |
| P5 | **ビジュアル再構築** | カラー復活（phase7のティール資産＋紺の追加）。タイポグラフィ主体のデザイン表紙を生成（写真は権利上、人間差し替え枠）。サイドバーのステップ進行アイコン、銘柄紹介のカラー表、Zoom写真の貼付枠 |
| P6 | **銘柄紹介の下書き強化** | 捏造禁止は維持しつつ、正典データから言える範囲（業種・役割・テーマ・スコア・証拠水準・「なぜこの役割か」の機械的根拠）まで**実文の下書き**を自動生成し、事業概要・定性根拠は［要IR確認］タグつき記入欄に |
| P7 | **人間パートの実行支援** | インタビュー質問草案を分析から自動生成（例：フジクラへ「光配線の受注動向」、学研へ「教育×高齢者事業の資本効率」）。基礎学習・学んだことは記入枠＋書き方ガイド |
| P8 | **パフォーマンス再フレーミング** | 順序を「役割寄与の物語（Emergingが牽引・Valueが緩衝）→リスク特性→誠実な限界（in-sample・1年IR負）」に。数値は不変、見せ方のみ変更 |
