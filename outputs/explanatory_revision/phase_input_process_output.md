# Phase 別 入力・処理・出力

各段階を「入力・問い・使用式・処理・出力・結論」で示す（本文にも掲載）。

## 守（Phase1）
| 項目 | 内容 |
|---|---|
| 入力 | 非金融普通株 3,099 社と財務・株価データ |
| 問い | いま完成した堀を持ち、割安で、こわれにくい会社はどれか |
| 使用式 | 1.0 時価総額 / 1.1 B/M / 1.2 E/P / 1.3 GP / 1.4 Piotroski / 1.5 Sloan / 1.6 流動性 / 1.7 危機ガードレール |
| 処理 | 段階的スクリーニング（下記ファネル）→通過77社から固定順で上位5社 |
| 出力 | Buffett Core 5社（3539・4350・6430・7803・9470）固定 |
| 結論 | 先行研究式のみで割安×優良×安全の完成した堀を再現 |

**ファネル（各段階の通過社数）**：3,099 → 2,740（B/M・E/P算出可）→ 583（Value条件）→ 146（Piotroski）→ 112（Sloan）→ 90（Distress）→ 77（流動性）→ Top5。

## 破（Phase2）
| 項目 | 内容 |
|---|---|
| 入力 | 守と同じ式・データ（3,099社） |
| 問い | 守の厳しさで見落とす変化・新生の候補を広く拾うには |
| 使用式 | 2.1 正規化 / 2.2 コンセンサス / 2.3 Phase2信頼度（守の式は不変） |
| 処理 | 閾値・分位・候補数のみ最適化。レビュー可能規模として Top1200 採用 |
| 出力 | 候補1,200社（Top2000は参照群） |
| 結論 | 候補を広げる判断が最終選定に最も効く（アブレーション A8=7） |

## 離（Phase3）
| 項目 | 内容 |
|---|---|
| 入力 | 候補1,200社＋確認フラグ・信頼度 |
| 問い | 変わる堀・生まれる堀を測り三世代20社をどう組むか |

## 配分（Phase4）
| 項目 | 内容 |
|---|---|
| 入力 | 選定済み20社＋株価・変動・流動性・証拠・信頼度 |

|---|---|
