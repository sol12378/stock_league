# 用語集（初学者向け）

本文で使う言葉の定義。ここで定義しない略語・記号は本文でも使わない。

| 用語 | やさしい定義 |
|---|---|
| 株価 | 市場でその会社の1株につく値段（円）。 |
| 発行済株式数 | 会社が発行した株式の総数。 |
| 時価総額 | 株価×発行済株式数。会社全体の市場価格。 |
| 売上高 | 1年間に売って得た金額。 |
| 売上総利益（粗利） | 売上高−売上原価。もうけの素。 |
| 営業利益 | 本業のもうけ。 |
| 純利益 | 最終的なもうけ。 |
| 自己資本（純資産） | 総資産−負債。会社の正味の元手。マイナスは債務超過。 |
| 総資産 | 会社が持つ全資産。 |
| 営業キャッシュフロー | 本業で入った現金の増減。 |
| PBR | 時価総額÷純資産。B/M の逆数。 |
| PER | 時価総額÷純利益。E/P の逆数。 |
| B/M | 純資産÷時価総額。大きいほど割安。 |
| E/P | 純利益÷時価総額。大きいほど割安。 |
| 堀（Moat） | まねしにくい持続的競争優位。 |
| ボラティリティ | 株価変動の大きさ＝リスク。 |
| ベンチマーク | 比較基準の市場指数（TOPIX・日経）。 |
| 超過リターン | ベンチマークを上回った分。 |
| in-sample | 分析と同じ期間で測った結果。将来を保証しない。 |
| Evidence Level | スコアの根拠の具体性（1〜3）。 |
