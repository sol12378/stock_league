# 通し計算例 ― 学研ホールディングス（9470・実データ）

守で選ばれた完成した堀の一社、9470 学研HD の**実測値**で、時価総額から最終投資額までを一つにつなぐ。全候補にすべての指標が計算されるため、1社で全ステップをたどれる。役割が分かれる判定点（⑨で Emerging が低いこと）を示すことで、恣意的でないことを確認できる。

| ステップ | 9470 学研HD の実際の値と判定 |
|---|---|
| ① 時価総額 | 株価 941円 × 約4,141万株 ≒ 389.7億円 |
| ② B/M | 1.526（純資産が時価総額の約1.5倍・市場上位30%）→関門①通過 |
| ③ E/P | 0.1215（PER約8倍・黒字割安）→関門②通過 |
| ④ Gross Profitability | 0.395（市場中央値以上）→関門③通過 |
| ⑤ Piotroski | 1.0（算出可能全シグナル合格）→関門④通過 |
| ⑥ Sloan | -0.0228（マイナス＝現金裏づけ厚く良質）→関門⑤通過 |
| ⑦ 危機ガードレール | 債務超過なし・3期連続赤字なし → D=0 通過 |
| ⑧ Phase2 信頼度 | 0.98（データ安定） |
| ⑨ 変わる堀／生まれる堀 | Transformation=73.4（高め）／Emerging=21.5（低い）→生まれる堀では選ばれない |
| ⑩ 役割割当 | 守Top5固定 → 完成した堀（Buffett Core）、Evidence Level L3 |
| ⑪ 配分優先度 | 変動小・流動性高(ℓ=1.00)・証拠L3(e=1.05)・信頼度0.98 → 役割内で厚め |
| ⑫ 最終投資額 | 目標比率 6.88% → 941円で 365株 → 343,465円（実測） |

結論：守の5関門を通り、変わる堀の評価は高いが生まれる堀は低いため、9470 は「完成した堀（Buffett Core）」に落ち着き、約34万円（6.88%）が配分される。数値はすべて正典データ（data_real.json / allocation_final.csv）に基づく。
