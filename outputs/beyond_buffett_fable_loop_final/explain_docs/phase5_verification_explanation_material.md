## 1. この章で言いたいこと（1文）
「Final20 と配分は、単一銘柄・単一テーマ・後付け最適化に依存しておらず、in-sample のリスク特性は健全だが、1年 IR が負である事実を含めて性能は主張しない。」

## 2. 検証の立場（最重要・繰り返し明記）
- ポートは 2026-06 データで構築 → **全区間 in-sample**。
- 数値は**リスク特性の確認**であって**将来リターンの予測ではない**。
- 銘柄はバックテスト成績で入替えない。配分は投資仮説とリスク制約のみで決定。

## 4. アブレーション（図表 VII-1 = ablation_overlap.png）
- A1〜A16。overlap（20中の一致数）で「どの要素が選定を駆動するか」を可視化。
- **A8（Top100限定）= 7 が最小** → 母集団の広さ（破）が最大の駆動要因。
- 単一スコアだけでは再現不可（A1=12, A2=16）→ 二軸合成が本体。
- ペナルティ・証拠制約は効くが支配的でない（10未満に落ちない）。
- **A16（D4）= 16** → ai_keyword_only ガードは過度に拘束的でない。
