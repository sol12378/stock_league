# Phase3「離」説明資料（explanation material）

| 役割 | 社数 | 銘柄（code 社名） |
|---|---|---|

| Transformation Core（変わる Moat） | 5 | 5902 ホッカンHD／9828 元気寿司G／5233 太平洋セメント／8037 カメイ／3863 日本製紙 |
| Emerging Core（生まれる Moat） | 5 | 6368 オルガノ／6315 TOWA／6920 レーザーテック／6526 ソシオネクスト／5803 フジクラ |

- 業種: 上限3遵守（Retail・Machinery・情報通信・電機 各3が最大）／テーマ: non_ai 10・上限4遵守
- Evidence Level（役割別・修正済み）: **L3 = 15 社・L2 = 4 社・L1 = 1 社**
- 除外監査: 862 社（AIキーワードのみ 577／上位互換 221／distress・品質 32／トラップ 17／低PBRのみ 15）

## なぜ「離」か

- Phase1（守）: 完成した Moat を先行研究式で抽出 → **過去〜現在**
- Phase2（破）: 式を変えず使い方を最適化し候補宇宙を形成 → **現在の広がり**
- Phase3（離）: 「変わる Moat」「生まれる Moat」を新たに定義して測定 → **現在〜未来**

「離」の独自性は新式の発明ではなく，**先行研究式の部品を未来時制へ再構成した**ことにある（B/M・E/P → 評価ギャップ，Piotroski → 改善・実行信頼性，Sloan → トラップ耐性，Novy-Marx GP → 無形資産・価格決定力）。再構築検証で実装と式の誤差 0.0 を確認済み。

## 何が「低PBR株選定」「AIテーマ株選定」と違うのか

| ありがちな失敗 | 本設計の防御 |
|---|---|
| 低PBRを買うだけ | 評価ギャップ単独では選定不可。TQ（定量改善証拠）=0 かつ value≥70 は low_pbr_only として除外（15社）。バリュートラップ・ペナルティで高アクルーアル・赤字CFを減点 |
| AIキーワードで買うだけ | キーワードのみ（L1）は Hype Penalty −18。ai_keyword_only は選定不可（577社除外）。L2+ には製品・顧客・数量根拠が必要 |
| バックテストで入替 | 選定後のリターンによる入替は禁止。検証（Phase5）はリスク確認と位置づけ |

## Evidence Level（5系統）

- TQ（変革の定量証拠 0–3）／TR（改革開示 0/1）／TS（株主還元 0–2）／EM（Emerging 開示 0–3）／final（役割別）
- **正直な開示**: TR は全社 1 で識別力なし（改革開示の構造化データ欠損）。TS は FCF プロキシの言い換え。Emerging L2+（14社）は開示個別確認（curated）に完全依存し，機械スクリーニングは L0/1 まで。
- v2 の final level 集計バグ（役割別分岐の未発火）は本ループで修正。**選定には影響なし**（ゲートは EM レベルと grade を使用）。

## 限界

1. 株主還元・改革開示データの欠損により Transformation は partial 形（full 到達不能）。
2. 開示を精読した企業しか L2+ になれない非対称性（過小評価リスク）。
3. ai_keyword_only ガードが E≈0 の純 Transformation 高スコア銘柄も除外する保守設計（影響は Phase5 A16 で定量化）。
4. 合成式の重みは概念設計係数（±20% 感度で選定不変を確認済み）。
