# Phase4 Review Comments（loop 1）

## 良い点

1. **v2 配分の致命傷（消化率 47.5%・5〜9社購入不可）を根本解決**：原因は「100株単元×8%上限」の衝突。STOCKリーグ規約（1株単位）を基準ケースに据え、消化率 99.0%・全銘柄購入可へ。単元制約は感度分析として誠実に残した。
2. **B案の退化の発見**：役割構成 5/5/5/3/2 では役割別予算（25/25/25/15/10）の役割内等分＝全銘柄5%となり、B案はA案と一致する。この観察により「C案は等金額からの説明可能な最小拡張」という理論的な位置づけが得られた。
3. **リターン非使用**：調整係数は逆ボラ・流動性・Evidence・データ信頼度のみ。バックテスト成績もリターン予測も配分に入れていない。
4. **D案を作った上で捨てる判断**：minvar はボラ 17.25% と最良だが、業種集中 24%・重みの説明困難性から参照にとどめた。「作らずに捨てる」のではなく「作って比較して捨てる」ことで説明力が増す。

## 懸念点と対応

1. **ボラ推定の不安定性**：直近1年（252営業日）の実現ボラは regime 依存。→ Phase5 で全期間ベースの指標と併記。
2. **係数の刻み（λ: 0.70/0.85/1.0、e: ±5%）は設計判断**：連続関数にしない理由は「読者が手計算で再現できる粒度」を優先したため。恣意性は Phase5 の頑健性確認で補う。
3. **ゼンリン 7.46% が最大**：低ボラ×L3×高流動性の帰結だが、単一銘柄への 8% 近接は下方イベントに脆い。→ リスク分析に記載。
4. **残現金 ¥50,801**：予備費として明記（手数料・価格変動バッファ）。
