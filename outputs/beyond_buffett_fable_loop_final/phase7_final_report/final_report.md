## 要旨

私たちは，投資の名手 Warren Buffett の本質が「持続的競争優位（Moat）を持つ企業を，割安に取得し長く保有する規律」にあると捉える。本レポートのテーマは「BEYOND BUFFETT（バフェットを超える）」である。ただしこれはバフェットの否定ではない。Moat を出発点として受け継ぎつつ，それを**静的な現在の状態から，時間とともに変化・新生する動的な概念へと拡張する**ことを意味する。

私たちは Moat を三世代に分けて測定した。すなわち，先行研究の式で抽出できる**完成された Moat**，資本効率改革によって**変わる Moat**，産業構造の転換によって**生まれる Moat**である。この三世代を，先行研究の式を「守り」，その使い方を「破り」，時間軸へ「離れる」という守・破・離のスクリーニングで選定し，完成・変化・新生の三世代からなる 20 社ポートフォリオを構築した。銘柄はバックテスト成績で入れ替えず，すべての選定を証拠水準・除外監査・感度分析・アブレーションによって説明可能にした点が本レポートの特徴である。

## Ⅰ．背景・投資テーマ決定

### 1．テーマ概要

本レポートは，次世代の日本株投資の姿として「三世代の Moat」を提示する。Warren Buffett の成果は天才的な直感ではなく，Value・Quality・低リスクという再現可能な規律に支えられていることが実証されている（Frazzini, Kabiller and Pedersen, 2018）。私たちはこの規律を出発点として受け継ぎつつ，「今の Moat」だけでなく「これから変わる Moat」「これから生まれる Moat」を測定し，投資対象とする。

### 2．なぜ現代日本株で Moat を拡張するか

第一に，日本株市場では東京証券取引所（2023）の資本効率改革要請を契機に，低く評価されてきた企業が資本効率改善・株主還元・事業改革を通じて**再評価される（＝Moat が変わる）**局面にある。伊藤レポート（経済産業省, 2014）以来の資本収益性重視の潮流がこれを後押しする。完成された Moat だけを見ると，この変化の途上にある企業を取りこぼす。

第二に，AI・半導体・データセンター・光通信・電力・自動化・セキュリティといった産業構造の転換により，**新たな競争優位が形成されつつある（＝Moat が生まれる）**。無形資産が企業価値の中心になりつつある一方で会計はそれを十分に捉えられていない（Lev and Gu, 2016；Peters and Taylor, 2017）。しかしこれを単純な「AI テーマ株買い」で捉えると，キーワードだけで実体を伴わない銘柄を掴むリスクがある。

### 3．投資テーマ決定 ― 守・破・離による三世代の Moat

以上を踏まえ，私たちは Moat を時間軸で三世代に拡張し，剣道等の修養段階になぞらえた「守・破・離」の三段階スクリーニングで選定する。

- **守**：先行研究の式を一切変えず，完成された Moat を段階的スクリーニングで抽出する。
- **破**：式は変えず，閾値・分位・通過条件・候補数という「式の使い方」を最適化し，候補宇宙を広げる。
- **離**：候補宇宙から，変わる Moat・生まれる Moat を測定し，三世代からなる 20 社を構築する。

本レポートの独自性は「新しい万能スコアの発明」ではなく，**意味の確立した既存の財務・会計指標を Moat の時間軸という枠組みへ再構成した点**にある（図表 I-1）。守・破・離の役割は図表 II-0 に示す。

### 第1スクリーニング：守 ― 完成された Moat

守では，バフェット型投資の規律を公刊された先行研究の式のみで再現する。独自の重み付き合成スコアは用いず，段階的スクリーニングとして運用する。

#### 1-1．使用指標

Value は簿価時価比率（式1）と益回り（式2），Quality は Gross Profitability（式3），財務健全性は Piotroski の available signal ratio（式4），利益の質は Sloan のアクルーアル（式5），流動性は 60 日平均売買代金（式6）で測る。破綻回避は Ohlson・Altman の原式が入力制約で実装不能なため，債務超過・連続損失・営業CF赤字による簡易ガードレールで代替する。

```formula
CAPTION: 図表 II-2｜簿価時価比率 B/M（Fama and French, 1993）
EQ: \mathrm{BM}_i = \dfrac{BE_i}{ME_i}
DEF: BE_i：自己資本（簿価），ME_i：時価総額。値が大きいほど割安（Value）を示す。
```

```formula
CAPTION: 図表 II-3｜益回り E/P（Basu, 1977）
EQ: \mathrm{EP}_i = \dfrac{E_i}{ME_i}
DEF: E_i：当期純利益。正で高いほど収益に対して割安。
```

```formula
CAPTION: 図表 II-4｜Gross Profitability（Novy-Marx, 2013）
EQ: \mathrm{GP}_i = \dfrac{\mathrm{Revenue}_i - \mathrm{COGS}_i}{\mathrm{TotalAssets}_i}
DEF: 売上総利益を総資産で除した，資産効率を伴う収益性（Quality）。
```

```formula
CAPTION: 図表 II-5｜Piotroski available signal ratio（Piotroski, 2000）
EQ: \mathrm{PF}^{\mathrm{avail}}_i = \dfrac{\sum_{s \in \mathcal{S}_i}\mathbf{1}[\text{signal }s\text{ passes}]}{|\mathcal{S}_i|}
DEF: \mathcal{S}_i：企業 i で算出可能な Piotroski シグナル集合。9 シグナル中 6 シグナルの部分実装のため，算出可能シグナル中の合格比率で評価する。
```

```formula
CAPTION: 図表 II-6｜Sloan Accruals（Sloan, 1996）
EQ: \mathrm{ACC}_i = \dfrac{\mathrm{NI}_i - \mathrm{CFO}_i}{\mathrm{TotalAssets}_i}
DEF: NI_i：当期純利益，CFO_i：営業キャッシュフロー。アクルーアルが大きいほど利益の質が低い。
```

```formula
CAPTION: 図表 II-7｜60日平均売買代金（流動性）
EQ: \mathrm{ADV}_{i,60} = \dfrac{1}{60}\sum_{d=1}^{60} P_{i,d}\,V_{i,d}
DEF: P_{i,d}：d 日前の終値，V_{i,d}：出来高。実務上 1,000 万円以上を優先。
```

#### 1-2．段階的スクリーニング手順

算出可能な非金融普通株 3,099 社を起点に，B/M 上位 30%・正の E/P 上位 50%（2,740 社）→ GP 中央値以上（583 社）→ Piotroski available ratio 0.65 以上（146 社）→ 高アクルーアル除外（112 社）→ distress 除外（90 社）→ 流動性フィルタ（77 社）と段階的に絞る（図表 II-2b）。独自の重み付き合成スコアは用いず，通過 77 社から固定順序の逐次比較（GP → E/P → B/M → Piotroski → Sloan → 流動性 → 時価総額）で上位 5 社を選ぶ。GP の業種バイアスを考慮し，同一業種は原則 2 社までとした。

#### 1-3．Buffett Core Top5

選定された 5 社（3539 JMホールディングス，4350 メディカルシステムネットワーク，6430 大黒電機，7803 ブシロード，9470 学研ホールディングス）は，いずれも Value（B/M 76〜80 パーセンタイル）と Quality（GP 71〜92 パーセンタイル）を同時に満たし，全ガードレールを通過した。**この 5 社を最終 20 社の Buffett Core として固定し，以降のスクリーニングで入れ替えない。** 守の限界は，Piotroski が 6/9 シグナルの部分実装であること，Ohlson・Altman 原式が未実装で簡易ガードレール代替であること，GP に業種バイアスが残ること，先行研究式は将来リターンを保証しないことである。

### 第2スクリーニング：破 ― 候補宇宙の形成

守の段階的スクリーニングは規律が強い反面，通過が 77 社に絞られ，変わる Moat・生まれる Moat の候補を評価する余地が乏しい。破では，**守の式そのものは一切変えずに**，閾値・分位・通過条件・正規化方式・候補数という「式の使い方」を最適化し，候補宇宙を広げる。

#### 2-1．閾値・分位・通過条件の最適化

7 指標を市場パーセンタイルで正規化（式8）し，指標の重み・ペナルティ（異常値・欠損・超小型株・一時的利益）・候補数・業種調整・欠損処理を，ランダムサーチにより比較した（Bergstra and Bengio, 2012）。採用解は正規化＝市場パーセンタイル，欠損処理＝コア指標欠損時除外，業種調整＝不採用である。正規化の頑健性は，市場・業種・ロバスト z・ウィンザライズ z の 4 方式で共通上位に残るかを示すコンセンサスタグ（式9，core 970 社・robust 1,135 社）で担保した。なお distress の重みは大きい（0.251）が，除去実験での目的関数低下はほぼゼロ（0.0017）である。これは distress が事前のハード除外で適用済みであり，通過母集団内では追加識別力が小さいためで，**重みの大きさを予測力と解釈してはならない**。

```formula
CAPTION: 図表 II-8｜市場パーセンタイル正規化
EQ: z^{\mathrm{mkt}}_{i,k} = \dfrac{\mathrm{rank}_{\Omega}(x_{i,k})}{N_{\Omega}}
DEF: x_{i,k}（指標 k の生値）を母集団 Ω 内の順位 rank に写し、母集団サイズ N_Ω で割って [0,1] に正規化する。守の式（1）〜（6）は変えず、値の使い方（閾値・分位）だけを最適化する。
```

```formula
CAPTION: 図表 II-9｜正規化コンセンサスタグ
EQ: \mathrm{Consensus}_i = \sum_{m \in \mathcal{M}} \mathbf{1}[\, \mathrm{rank}^{(m)}_i \le N \,]
DEF: M ＝｛市場, 業種, ロバスト z, ウィンザライズ z｝の 4 正規化方式。4 方式で共通して上位 N に入るほど頑健。core（全方式一致）970 社、robust 1,135 社。
```

#### 2-2．Top1200 候補宇宙

正式母集団は Top1200（1,200 社）である。候補数を効用（広さ・品質・安全性・流動性・業種分散・解釈可能性・レビュー負荷）で比較すると，広さを報酬する効用関数では Top2000 が最良となるが，本研究の目的は候補数の最大化ではなく「レビュー可能な候補宇宙」の形成であるため，**Top1200 を正式採用し Top2000 は取りこぼし確認用の参照群**とした。Top100・Top300 は優先確認レイヤである。業種集中は HHI 0.0707・最大業種シェア 11.6% と分散し，守の Top5 は全て Top1200 に含まれる（図表 II-9b）。

#### 2-3．離への接続

破の探索的重み付きスコアは候補宇宙形成の道具であり，**最終選定スコアとしては使用しない**。離へは，候補 1,200 社とレビューフラグ（正規化の頑健性・外れ値感応性・GP 定義の検証状態）と信頼度情報を引き渡す。破の限界は，厳密な walk-forward 検証が年度数の制約で未完了（EDINET 提出日ベースの point-in-time パネルで時点外検証を代替）であり，**将来リターンの予測力を主張しない**点である（Bailey et al., 2014）。

### 第3スクリーニング：離 ― Moat の時間軸拡張

守が抽出するのは「すでに完成された Moat」である。しかし Moat は静的ではない。離では，候補 1,200 社に対し，資本効率改革で**変わる Moat**と産業構造転換で**生まれる Moat**を測定し，完成・変化・新生の三世代からなる 20 社を構築する（図表 II-10）。

#### 3-1．変わる Moat（Transformation Moat）

Transformation Moat とは，現在の市場評価は低いが，資本効率改善・株主還元・事業改革・経営姿勢の変化により企業価値が再評価される可能性を指す。**これは低 PBR 株の選定ではない。** 評価ギャップ・資本効率改善・還元余力・実行信頼性・利益の質を式（10）（設計形）で合成し，バリュートラップ・ペナルティを控除する。評価ギャップが大きくても定量的改善証拠を欠く銘柄は low-PBR-only として除外した（15 社）。株主還元・改革開示の構造化データが入手できなかったため，設計完全形（式10）ではなく **partial 形（式11）**で運用し，スコア種別（partial 19 社・lite 1 社）として開示する。重みは事後リターン最適化ではなく概念上の設計係数であり，±20% の摂動でも選定が不変であることを感度分析で確認した（1,200 社順位の Spearman ρ は Transformation で最小 0.997・Emerging で最小 0.994）。

```formula
CAPTION: 図表 II-11｜Transformation Moat Score（設計形）
EQ: S^{\mathrm{Trans}}_i = 100\left(w_V V_i + w_C C_i + w_R R_i + w_E E_i + w_X X_i + w_Q Q_i\right) - P^{\mathrm{Trap}}_i
DEF: V_i 評価ギャップ，C_i 資本効率改善，R_i 株主還元，E_i 改革開示，X_i 実行信頼性，Q_i 利益の質，P^{\mathrm{Trap}}_i バリュートラップ罰。設計重み w_V0.20/w_C0.22/w_R0.16/w_E0.17/w_X0.13/w_Q0.12。
```

```formula
CAPTION: 図表 II-12｜Transformation Moat Score（partial 実装形）
EQ: S^{\mathrm{Trans,partial}}_i = 0.22 V_i + 0.24 C_i + 0.10 F_i + 0.18 X_i + 0.16 Q_i + 0.10 \Phi_i - P^{\mathrm{Trap}}_i
DEF: 株主還元 R_i・改革開示 E_i の構造化データが入力に無いため，R_i を FCF プロキシ F_i（営業CF−CAPEX>0 で還元余力）で代替，E_i を除外，Phase2 信頼度 \Phi_i を加える。[0,100] にクリップ。full 形は構造的に到達不能。
```

#### 3-2．生まれる Moat（Emerging Moat）

Emerging Moat とは，AI・データセンター・半導体・電力・光通信・自動化・セキュリティ・業務データ・品質保証といった産業構造変化により新たに形成される競争優位を指す。**これは AI テーマ株の選定ではない。** 無形資産・イノベーション能力・ボトルネック性・AI 産業基盤接続・データ顧客基盤・信頼安全基盤の 6 要素を式（12）で合成する。証拠ボーナスは最大 +8 に抑え，**キーワードのみの言及には 18 点のテーマ過熱ペナルティ**を課す。AI キーワードに触れるだけで具体的証拠を欠く 577 社はすべて除外・監査記録した。

```formula
CAPTION: 図表 II-13｜Emerging Moat Score（Emerging 産業基盤マップ）
EQ: S^{\mathrm{Emerg}}_i = 100\left(w_I I_i + w_N N_i + w_B B_i + w_A A_i + w_D D_i + w_T T_i\right) + B^{\mathrm{Evidence}}_i - P^{\mathrm{Hype}}_i - P^{\mathrm{Guard}}_i
DEF: I_i 無形資産，N_i イノベーション，B_i ボトルネック性，A_i AI基盤接続，D_i データ顧客基盤，T_i 信頼安全基盤。重み w_I0.18/w_N0.15/w_B0.18/w_A0.22/w_D0.14/w_T0.13。B^{\mathrm{Evidence}}\le8 証拠ボーナス，P^{\mathrm{Hype}} キーワードのみ18点罰，P^{\mathrm{Guard}} 財務ガード罰。
```

#### 3-3．Evidence Level

証拠の強さはスコアと分離して 5 系統で管理する（式13）。Emerging 開示レベルは，キーワードのみ＝Level 1，製品・用途・顧客・投資計画の具体性＝Level 2，売上・受注・CAPEX 等の数量根拠＝Level 3 と定義する。Level 2 以上の 14 社は有価証券報告書・決算説明資料の個別確認によるもので，機械的スクリーニングでは Level 0〜1 までしか到達できない。この非対称性は過小評価リスクとして限界に記す。最終 Evidence Level は役割別に定義し，最終 20 社の分布は Level 3 が 15 社・Level 2 が 4 社・Level 1 が 1 社である。

```formula
CAPTION: 図表 II-14｜最終 Evidence Level（役割別）
EQ: L^{\mathrm{final}}_i = \begin{cases} \min(L^{TQ}_i, L^{EM}_i) & \text{Dual Moat}\\ L^{EM}_i & \text{Emerging Core}\\ \max(L^{TQ}_i, L^{TS}_i, L^{TR}_i) & \text{Transformation Core}\\ \max(L^{TQ}_i, L^{EM}_i) & \text{その他}\end{cases}
DEF: L^{TQ} 定量証拠，L^{TS} 株主還元証拠，L^{TR} 改革開示，L^{EM} Emerging 開示。Level1=キーワードのみ，2=製品/顧客/投資計画，3=売上/受注/CAPEX 等の数量根拠。
```

#### 3-4．最終 20 社の役割設計

### 1．ポートフォリオ配分決定

配分はバックテスト成績ではなく**投資仮説（時間軸分散）とリスク制約**で決める。役割別予算を Buffett/Transformation/Emerging 各 25%・Dual 15%・Bridge 10% と置き，役割内を逆ボラティリティ×流動性×Evidence×信頼度で傾ける Risk-adjusted Role Allocation（式14）を採用した。単元株調整は式（15）による。基準ケース（単元未満株 L=1，STOCK リーグ規約）で 20 銘柄すべて購入可能，投資額 ¥4,949,198・残現金 ¥50,801（消化率 99.0%）である。最終配分を図表 III-1 に示す。

```formula
CAPTION: 図表 III-0a｜Risk-adjusted Role Allocation（採用案）
EQ: \omega_i = B_{r(i)}\cdot\dfrac{\rho_i}{\sum_{j:r(j)=r(i)}\rho_j},\quad \rho_i = \dfrac{1}{\max(\sigma_i,0.10)}\cdot\ell_i\cdot e_i\cdot c_i
DEF: r(i) 役割，B_r 役割予算（Buffett/Trans/Emerging 0.25，Dual 0.15，Bridge 0.10）。\rho_i は逆ボラ×流動性 \ell_i×Evidence 係数 e_i×信頼度 c_i。\omega_i>0.08 は 8% に制限し同役割内で再配分。リターン予測は不使用。
```

```formula
CAPTION: 図表 III-0b｜単元株調整購入株数
EQ: q_i = L_i\left\lfloor \dfrac{B\,\omega_i}{P_i L_i}\right\rfloor
DEF: q_i 購入株数，L_i 売買単位，B 総予算（500万円），\omega_i 目標比率，P_i 株価。基準 L_i=1（単元未満株），感度 L_i=100（実単元では9社購入不可）。
```

### 3．パフォーマンスの分析

**フレーミング（重要）**：本ポートフォリオは 2026-06 時点のデータで構築されており，あらゆる履歴シミュレーションは構造上 in-sample である。以下の数値は**リスク特性の確認**であって**将来リターンの予測や優位性の主張ではない**。ベンチマークは TOPIX プロキシ（1306.T）と日経225（^N225）を用い，1306.T の未調整 1:10 分割（2026-03-30）は補正した（注1）。

主要なリスク指標の定義を式（図表 III-2a〜III-2d）に示す。3 年（in-sample）で年率リターン +30.8%（TOPIX +24.1%・日経 +32.8%），ボラティリティ 21.9%，最大ドローダウン −24.9%（TOPIX −23.3%），β 0.925，Sharpe 1.41，Sortino 1.62，Jensen α +7.3%/年，Information Ratio +0.445 であった。

```formula
CAPTION: 図表 III-2a｜Sharpe Ratio（Sharpe, 1966, 1994）
EQ: \mathrm{Sharpe} = \dfrac{\bar{r}_p - r_f}{\sigma_p}
DEF: \bar{r}_p：年率ポートフォリオ収益，r_f：無リスク金利（本研究では約 0），\sigma_p：年率ボラティリティ。
```

```formula
CAPTION: 図表 III-2b｜Maximum Drawdown
EQ: \mathrm{MDD} = \min_{t}\left(\dfrac{C_t}{\max_{s\le t} C_s} - 1\right)
DEF: C_t：時点 t の累積指数。ピークからの最大下落率。
```

```formula
CAPTION: 図表 III-2c｜Jensen's α（Jensen, 1968）
EQ: \alpha_p = \bar{r}_p - \beta_p\,\bar{r}_m,\quad \beta_p = \dfrac{\mathrm{Cov}(r_p, r_m)}{\mathrm{Var}(r_m)}
DEF: r_m：TOPIX プロキシ収益。\beta_p で説明されない超過収益が \alpha_p。
```

```formula
CAPTION: 図表 III-2d｜Herfindahl–Hirschman Index（集中度）
EQ: \mathrm{HHI} = \sum_{g}\left(\sum_{i\in g}\omega_i\right)^{2}
DEF: g：銘柄・業種・テーマの各グループ。値が大きいほど集中。本研究では銘柄 0.053・業種 0.123・テーマ 0.402。
```
一方，**直近 1 年では Information Ratio が −0.405（負）**であり，ベンチマーク超過を作れていない。3 年と 1 年で符号が反転する事実を隠さず提示し，性能を主張しない立場を明確にする。集中度は HHI で銘柄 0.053・業種 0.123・テーマ 0.402 で，テーマ HHI の高さをテーマ集中リスクとして開示する。役割別寄与は Emerging Core が支配的（+1.78%pt），Buffett Core はほぼゼロ（+0.02%pt）で，Buffett Core が「リターン源」ではなく「安定土台」を担う設計と一致する。Leave-one-out ではどの 1 社を除いてもボラは 0.210〜0.229 に収まり単一銘柄依存はない。除外変種では AI 基盤テーマ除外でリターン半減（+17.5%），低 PBR 除外でボラ 35.5%・MDD −44.5% に悪化し，**Value 名がリスク緩衝として機能**することが確認された。ドローダウンと役割寄与を図表 III-3・III-4 に示す。
