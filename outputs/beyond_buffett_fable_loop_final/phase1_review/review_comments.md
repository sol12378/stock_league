# Phase1 Review Comments（loop 1）

## 良い点

1. **「守」の純度が高い**：B/M・E/P・GP・Piotroski・Sloan がすべて公刊研究の式定義そのままで、独自の重み付き合成スコアを一切使っていない（`top5_selection_rule` に明記）。逐次 tie-break は順序が固定されており恣意性が低い。
2. **ファネルの完全開示**：3,099→2,740→583→146→112→90→77→Top5 の各段の社数が CSV で追跡でき、レビュー可能性が高い。
3. **guardrail の誠実さ**：Ohlson/Altman が実装できないことを隠さず、attempt ファイルと欠損変数一覧まで出力している。この「できなかったことの開示」は論文の信頼性に直結する。
4. **Top5 の質**：5社とも Value（B/M 76〜80パーセンタイル、E/P 82〜97パーセンタイル）と Quality（GP 71〜92パーセンタイル）を同時充足。distress・異常値・流動性すべてクリア。

## 懸念点と対応

1. **GP の業種バイアス**：Novy-Marx の GP は資産回転の速い小売業で高く出やすく、Top5 の上位2社（3539, 4350）が Retail Trade。→ 「同一業種2社まで」上限が機能しており、Phase3 の役割設計（Buffett Core は安定土台に限定、20〜25%）でさらに希釈される。説明資料に明記。
2. **Piotroski 6/9**：available ratio ≥ 0.65 という通過条件は、6実装シグナル中4以上を要求する設計。原式 F-Score との差は限界節で開示する。
3. **配当の再取得値の乖離（6430）**：Phase4 の配分では配当を配分根拠に使わないため選定・配分への影響はないが、レポートに数値を書く場合は trailing ベースを併記する。
4. **rank 非連続の見た目**：final20（sector-adjusted）と Top5 の関係を知らずに読むと Top5 の抽出が恣意的に見えるリスク。説明資料で「業種上限による圧縮」を図解した。

## 結論

Phase1 は再実行不要。説明資料の一元化（本ループで実施）と Phase7 での限界記述で 96 点の残余を吸収する。
