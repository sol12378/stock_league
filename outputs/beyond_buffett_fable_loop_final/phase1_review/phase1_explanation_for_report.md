# Phase1 レポート転用文（最終論文 Ⅲ章「Phase1：守」用ドラフト）

## Ⅲ．Phase1：守

### 1．目的

Phase1 の目的は，バフェット型投資の本質である「持続的競争優位（Moat）を持つ企業を割安に取得する」という規律を，公刊された先行研究の式のみで再現することである。本研究ではこれを守・破・離の「守」と位置づける。ここで独自の工夫を加えないことが，Phase2 以降の拡張の独自性を測る基準線となる。

### 2．使用指標

Value は Fama and French（1993）の B/M（式（1））と Basu（1977）の E/P（式（2）），Quality は Novy-Marx（2013）の Gross Profitability（式（3）），財務健全性は Piotroski（2000）に基づく available signal ratio（式（4）），利益の質は Sloan（1996）のアクルーアル（式（5））を用いた。破綻回避については，Ohlson（1980）・Altman（1968）の原式が入力変数の制約で実装不能であったため，債務超過・連続損失・営業キャッシュフロー赤字等による簡易ガードレールで代替し，その旨を明示する。

### 3．スクリーニング手順

指標算出可能な非金融普通株 3,099 社を起点に，B/M 上位 30%・正の E/P 上位 50%（2,740 社）→ Gross Profitability 中央値以上（583 社）→ Piotroski available ratio 0.65 以上（146 社）→ 高アクルーアル除外（112 社）→ distress 除外（90 社）→ 流動性フィルタ（77 社）の段階的スクリーニングを行った。独自の重み付き合成スコアは用いず，通過 77 社から固定順序の逐次比較（GP → E/P → B/M → Piotroski → Sloan → 流動性 → 時価総額）で上位 5 社を選んだ。Gross Profitability の業種バイアスを考慮し，同一業種は原則 2 社までとした。

### 4．Buffett Core Top5

選定された 5 社（3539 JMホールディングス，4350 メディカルシステムネットワーク，6430 大黒電機，7803 ブシロード，9470 学研ホールディングス）は，いずれも Value（B/M 76〜80 パーセンタイル）と Quality（GP 71〜92 パーセンタイル）を同時に満たし，distress・異常値・流動性の全ガードレールを通過した。この 5 社を最終 20 社の Buffett Core として固定し，以降の Phase で入れ替えを行わない。

### 5．限界

第一に，Piotroski は 9 シグナル中 6 シグナルの部分実装である。第二に，Ohlson・Altman の原式は未実装であり，簡易ガードレールによる代替である。第三に，Gross Profitability は業種による出やすさの差があり，業種上限により部分的にしか緩和できていない。第四に，現時点データによる検証には look-ahead bias の懸念が残る（Phase2 の point-in-time パネルで部分対処）。第五に，先行研究式は将来リターンを保証せず，Phase1 の目的はあくまで「完成された Moat の抽出」である。
