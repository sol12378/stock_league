# Phase5 — 市場比較・リスク指標検証

**フレーミング（全文書共通・厳守）**
本ポートフォリオ（Final20・配分案C）は 2026-06 時点で入手可能なデータから構築されている。したがって、いかなる過去区間の履歴シミュレーションも構造上 **in-sample** である。本節の数値は**リスク特性の確認（ボラティリティ・ドローダウン・β・集中度・寄与分解）**であり、**将来リターンの予測や優位性の主張ではない**。この立場は要項が重視する「誠実な限界記述」に対応する。

**データと補正**
- 価格: `data/processed/prices_daily.parquet`（`adj_close`、2021-06-01〜2026-06-01）。
- ベンチマーク: TOPIX プロキシ = `1306.T`（NEXT FUNDS TOPIX ETF）、日経 = `^N225`。
- **データ修理（重要）**: `1306.T` に未調整の 1:10 分割（2026-03-30）が原系列に混入しており、同日に −90.2% の断崖が出る。同日以降の価格を **×10 補正**して連続化した。ポートフォリオ構成銘柄には分割様の断崖はなく（2112.T の 2024-01-25 +32.9% は実変動として保持）、補正は 1306.T のみ。補正ロジックは `scripts/phase5_validation.py` 内 `SPLIT_FIXES` に集約。
- ウェイト: 配分案C（`phase4_portfolio_allocation/allocation_final.csv` の `target_weight_final`）を固定ウェイトとして日次リバランス。
- 一次ソース: `phase5_validation_summary.json`。

- 3年 in-sample では TOPIX を上回るが日経には劣後。β<1・MDD が TOPIX 並みで、**過度にリスクを取っていない**プロファイル。

## 2. リスク調整済み指標

| 指標 | 3年 | 1年 |
|---|---:|---:|
| Sharpe Ratio | 1.41 | 2.04 |
| Sortino Ratio | 1.62 | 2.56 |
| Jensen's α（年率, 対 TOPIX） | +7.3% | +3.6% |
| Information Ratio | **+0.445** | **−0.405** |

- **1年窓では TOPIX に対して IR が負（−0.405）**。これは重要な誠実開示材料である：直近1年ではベンチマーク超過を作れておらず、**「予測力を主張しない」立場と整合**する。3年と1年で符号が反転する事実そのものを限界として提示する（`risk_analysis.md` §バックテスト過信）。

## 3. 集中度（HHI）

| 対象 | HHI | 目安 |
|---|---:|---|
| 銘柄 | 0.053 | 20銘柄・上限8%なので低集中（等金額=0.05） |
| 業種 | 0.123 | 中程度 |
| テーマ | **0.402** | **高い**——AI/半導体・光通信テーマへの傾斜を示す（リスク分析で明示） |

テーマ HHI が高いことは、Emerging 軸が「生まれる Moat」を狙う設計の帰結であると同時に、**テーマ集中リスク**として正直に開示すべき点である。

## 4. 寄与分解（3年 in-sample, 累積リターンへの %pt 寄与）

**役割別**

| 役割 | 寄与(%pt) |
|---|---:|
| Emerging Core | +1.78 |
| Transformation Core | +0.22 |
| Bridge / Diversifier | +0.10 |
| Dual Moat | +0.06 |
| Buffett Core | +0.02 |

- Emerging Core が支配的、Buffett Core はほぼゼロ。**Buffett Core は「リターン源」ではなく「安定土台」**という役割設計と一致（β<1・低ボラを担う）。図: `../figures/role_contribution.png`。

**テーマ別トップ**: 光通信 +1.29 / 半導体 +0.45 / non_ai +0.33。**トップ寄与銘柄 = 5803 フジクラ**（単独 +1.29）。→ この1社依存を Leave-one-out と除外変種で検証。

## 5. Leave-one-out（3年ボラ/MDD, `leave_one_out.csv`）
- 各1社を抜いて再正規化した20通り。ボラ範囲は **0.210〜0.229**——どの1社を抜いてもボラ水準は大きく動かず、**単一銘柄がリスク構造を支配していない**。
- フジクラ（5803）除外でボラ 0.212・MDD −0.256。リターン寄与は大きいがリスク寄与は平均的。

## 6. 除外変種（`exclusion_variants.csv`）

| 変種 | 銘柄数 | 年率リターン | ボラ | MDD |
|---|---:|---:|---:|---:|
| トップ寄与除外（5803） | 19 | +25.2% | 21.2% | −25.6% |
| **AI基盤テーマ除外** | 12 | +17.5% | 19.2% | −19.4% |
| **低PBR（PBR≤1）除外** | 8 | +56.9% | 35.5% | −44.5% |

- **AI基盤テーマ除外**でリターンはほぼ半減しボラは低下——Emerging 軸が in-sample のリターン源かつリスク源。
- **低PBR除外**でリターンは増えるが**ボラ 35.5%・MDD −44.5%**に悪化。**Value（Transformation の低PBR名）がリスク緩衝として機能**しており、AI 一辺倒でない設計の合理性を裏づける。

---

## 7. 結論
3年 in-sample では良好なリスク調整プロファイル（β<1, Sharpe 1.41, α +7.3%）だが、1年 IR が負であり**性能を主張しない**。本節の価値は「Final20 が単一銘柄・単一テーマに依存せず、Value と Emerging が相互にリスクを補完している構造」を確認した点にある。詳細な限界は `risk_analysis.md`、構造検査は `ablation_report.md` を参照。
