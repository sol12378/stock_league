# 査読のお願い — 『BEYOND BUFFETT: 三世代の堀』(日経STOCKリーグ提出版 v5)

## 研究要約(5行)

1. バフェットの選定規律を先行研究の式のみで再現し(守: B/M・E/P・粗利÷総資産・Piotroski 6項目・Sloan・危険よけ・流動性の七関門)、その5社を「比較の基準線」として固定保有します。
2. 同じ式の使い方だけを調整して候補1,200社を作り(破: 重みはランダムサーチ等3系統1.8万試行で効用最大化・成績は目的関数に不使用)、独自の物差し(離: 変わる堀・生まれる堀の点数+証拠水準の関所)で最終20社(5/5/5/3/2)を構成しました。
3. 検証は、同一の出発点(3,099社)から守の式だけで組んだ対照群『純正バフェットPF』との比較を主とし、事前宣言した5物差し×2期間で行いました(固定重み日次リバランス規約・BH併記)。
4. 結果: 対照群には3年+17.4pt(NW-t=2.26, 5%有意)・直近1年+25.9pt(t=1.93, 10%水準)。一方TOPIXには3年+5.8pt(t=0.81, 非有意)・直近1年-6.0pt(非有意)で、市場平均に勝つとは統計的に言えません。防御(β・最大下落)は対照群が優位です。
5. すべてin-sample(2026-06構築の選定を過去に当てはめた)特性であり、将来リターンの予測力は主張しません。全数値は正典データ(JSON/CSV)からの自動転記で、除外1,180社の理由・シード・再現手順まで技術補遺に開示しています。

## 特に意見を求めたい論点(5つ)——どこを叩いてほしいか

1. **in-sample比較設計の妥当性**: 「同一出発点の対照群と、選定に成績を使わない設計」でin-sample比較にどこまで意味を持たせられるか。追加すべき対照(ランダム20社の分布・サイズ/バリュー調整後など)があればご指摘ください(補遺§G①)。
2. **リターン寄与の帰属**: 3年寄与の8割が生まれる堀(AI関連)に集中しています。この超過を「設計が意図どおり動いた確認」と読む本レポートの整理は妥当か、それとも単一テーマの幸運と読むべきか(補遺§G②・図表Ⅲ-9)。
3. **有意性の扱い**: 日次超過のNewey-West検定+16通り検査を「多重検定の文脈で保守的に読む」という処理で十分か。Romano-Wolf型の同時検定やブートストラップを本件規模で実施する価値はあるか(補遺§F)。
4. **証拠水準という順序尺度**: 役割で意味が異なる順序尺度(生まれる堀=開示の具体性/変わる堀=財務改善の本数、TR・TSは現データで識別力なし)を選定の関所に使う設計の穴はどこか(補遺§B-4・§G)。
5. **三世代構成の資産配分としての解釈**: 25/25/25/15/10の役割予算+逆ボラ配分は、実務の目線でどう評価されるか。「完成した堀25%が防御を担う」という説明は配分理論として成立しているか(補遺§B-5)。
