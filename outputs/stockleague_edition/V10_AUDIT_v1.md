**やること: 「主対照20社のうち7社は本PFと同一（守5は定義上必ず含まれる）。したがって差の検定は保守的に出る」と一行入れる。**これだけで済む。

## B-2 主対照の「20社」はデータ可用性で決まっている

本文は主対照を「品質関門を通過し価格順位を付けられた20社（**社数を切らない**）」と説明する。
これは「20という数を恣意的に選んでいない」という主張として読める。実際は——

| | 実測 |
|---|---|
| 品質関門通過 | 166社（対照側の母集団） |
| うち時価総額データあり＝主対照の全量 | **20社** |
| コード | `build_control_v10.py`: `assert len(p) == 20` ← 20を前提に固定 |
| 感応度の「15社」の作り方 | `pick(p, 99)` で99社要求 → 業種上限2で15社しか取れない |

つまり感応度の「社数3通り（12／15／20）」のうち、**20はデータ可用性、15は業種上限で自動的に決まっており、独立した3つの選択肢ではない**。
ファネル1-7には「時価総額データの在庫がなく」の注記があるが、**対照群の節にはこの由来が書かれていない**。

## B-3 期首加重の実装が「当時実際に組めた重み」になっていない

本文の主張: 「期首加重＝各測定窓の期首株価×発行済株数（＝**当時実際に組めた重み**）」

実装（`build_control_v10.py`）:
```python
shares  = p["shares_outstanding"]          # 2026年時点の株数（1点のみ）
sub     = wide.tail(window).ffill()        # adj_close（配当・分割調整後）
px_ref  = sub.iloc[0]                      # 3年前の調整後株価
mc      = px_ref * shares
```

- **問題1**: `shares_outstanding` は2026年時点の値。自己株買い・増資・分割で株数は動くので、3年前の時価総額にはならない。「当時実際に組めた重み」という主張は成立しない。
- **問題2**: `adj_close` は配当・分割調整後の系列。調整後株価×現在株数は時価総額ではない（高配当銘柄の期首時価総額が過小になる）。

**ただし実害は小さい。**未調整 `close` で組み直すと重みの乖離は**最大0.22pt（4716 日本オラクル）・合計1.48pt**、
期間中に分割・多額配当で `close/adj` 比が1.5倍以上動いた銘柄は**0社**だった。
→ **数値の訂正は不要。「当時実際に組めた重み」という言い方を「期首株価×直近の発行済株数で近似した重み」に直すだけで足りる。**

## B-4 宣言した上限25%を実装が超えている

`w = (mc/mc.sum()).clip(upper=0.25); w /= w.sum()` ——clip後に1回だけ再正規化するため、
**再正規化で上限を超える**。実測の最大ウェイトは**27.2%**。
規約文（`control_comparison_v10.json`）は「期首時価総額加重(上限25%)」と書いている。
反復再正規化に直すか、規約文を「上限25%でclip後に再正規化（結果として最大27.2%）」に直す。

# C群 スクリーニング指標そのものの粗

## C-1 営業利益成長率のCAGRが「赤字年を捨てて」計算されている

`src/data/build_fundamentals.py:23-31`:
```python
clean = clean[clean[metric] > 0]        # ← 負の年を除外
years = max(1, len(clean) - 1)
return (last / first) ** (1 / years) - 1
```

| | 実測 |
|---|---|
| base 1,791社のうち営業利益の赤字年を除外された企業 | **151社（8.4%）**（1年除外127社・2年20社・3年4社） |
| うち守ゲート162社に入った | 0社（守は3期無赤字を別に課すため） |
| **最終20社のうち該当** | **2社：5214 日本電気硝子・9503 関西電力**（どちらも破＝変わる堀） |

帰結が二つある。

1. **赤字→黒字回復の企業が「安定成長」に見える。**赤字年が消えるので、成長率が実態より良く出る。関西電力はまさにこの型。
2. **成長率の計算期間が企業ごとに違う。**提出20社のうち18社は2年のCAGR、上記2社は**1年の変化率**。
   同じ「増収増益」「成長」という数字がz化されて比較されているのに、**測っている期間が違う**。

**これは破（変わる堀）の中核指標に直接効く欠陥で、v10は未開示。**

## C-2 「3期無赤字」に年数ガードがない（コードの穴）

守ゲートは `operating_loss_years_3y == 0` だけを見る。`operating_income_years_available >= 3` を課していないので、
**開示が1年しかない企業も「3期無赤字」を通過できる**（`0 == 0` が成立するため）。

実データでの該当は軽い——守ゲート162社のうち営業ＣＦの年数が3年未満なのは**1社**、
base 1,791社で営業利益の年数が3年未満なのは**2社**、**最終20社は全社3年そろっている**。
→ 修正は1行（`& (years_available >= 3)`）。結果は変わらないが、穴を残したまま「3期無赤字」と書くのは危険。

根本原因は `fetch_yfinance.py` が時価総額系データを**売買代金上位300社で打ち切って**取得していること
（取得済300社の売買代金順位は1〜300位で完全一致＝規模と完全相関）。適格1,791社中**139社(7.8%)**。

| `transformation_score` の重み構成 | 合計0.90、うち**0.70(78%)がyf限定**。σは0.516（データ有り）対0.140（無し）で3.7倍差。上位5社は100%がデータ有り組。**欠測分を外すと破5は重複0社** | 未開示 |
