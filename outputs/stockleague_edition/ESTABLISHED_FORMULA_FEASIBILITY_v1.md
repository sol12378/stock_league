# 自作の式をやめ、既存の式だけでスクリーニングできるか — 実行可能性の徹底調査 v1

問い(ユーザー): 式を自分たちで作り出すと認知限界を超えて理解できなくなる。**既存の式だけでスクリーニングを達成できないか。**

調査日: 2026-08-17 / 再現コード: `work/new_4axis_screen/11〜13_*.py` / 実測値: `work/new_4axis_screen/out/established_*.json` `ev_fields*.csv`

---

## 総括

**可能。しかも自作版より成績が良い。**

4軸すべてを、査読論文または著名な実務書で定義が確定している式に置き換えられた。前向き検証3コホートすべてで、既存式のみの版が自作版の順位相関を上回った(0.101 対 0.092 / 0.241 対 0.204 / 0.200 対 0.142)。現在の基準日で実際に回すと12業種20社が出る。

**これを可能にしたのは、式の工夫ではなくデータ抽出バグの是正である。** `src/data/parse_edinet_xbrl.py` が研究開発費を `ResearchAndDevelopmentExpenses` というタグで探していたが、EDINETの実タグは `ResearchAndDevelopmentExpensesSGA` だった。正しいタグで取り直すと研究開発費は **0.1% → 56.3%**、設備投資は **4.4% → 98.0%** に回復し、これまで「データがないから作れない」としていた既存式が軒並み実装可能になった。

**ただし「式」は全部既存にできるが、「しきい値」は自作が残る。** これは避けられない区別なので §F に分けて書く。

# A. 現状の棚卸し — どこが自作だったか

| 要素 | 出典 | 判定 |
|---|---|---|
| `moat_score` = 0.35収益性 + 0.25現金創出 + 0.20安定性 + 0.20競争優位 | なし | **自作** |
| `transformation_score` = 0.35z(1/PBR) + 0.20z(1/PER) + 0.20成長 + 0.15配当 | なし | **自作**(重み合計が0.90で1にならない) |
| `future_moat_score` = キーワード5分類の重み付き和 | なし | **自作** |
| `valuation_score` = 0.50z(1/PER) + 0.35z(1/PBR) + 0.15配当 | なし | **自作** |
| 4軸を25%ずつ | ― | 設計判断(式ではない) |
| 同一業種2社まで | ― | 運用ルール(式ではない) |

**4軸すべての式が自作だった。** 個々の材料(ROE・PBR・営業利益率)は標準的だが、**それらをどう重み付けて合成するかが全部オリジナル**であり、ここが「理解できなくなる」の正体である。重み合計が0.90になっている `transformation_score` は、自作であることの端的な証拠でもある。

# B. 既存式への置き換え — 軸ごとの可否

| 軸 | 置き換え先 | 出典 | 可否 | カバレッジ |
|---|---|---|---|---|
| ① Moat | **QMJ Profitability** = z平均(GPOA, ROE, ROA, CFOA, GMAR, −ACC) | Asness, Frazzini & Pedersen (2019) | **○** | 94.2〜100% |
| ② Change | **Piotroski F-Score** 9項目の合計 | Piotroski (2000) | **○** | 100% |
| ③ Future | **研究開発集約度** R&D/時価総額・R&D/売上 | Chan, Lakonishok & Sougiannis (2001) | **○** | 開示65.0% |
| ④ Price | **益回り EBIT/EV** + **B/M** + **E/P** | Greenblatt (2005) / Fama & French (1992) / Basu (1977) | **○** | 96.8〜100% |
| 合成 | **順位合算方式**(各軸の順位を足す) | Greenblatt (2005) | **○** | ― |
| Step 0 | **Z-Score**(<1.81を除外) / **流動性** | Altman (1968) / Amihud (2002) | **○** | 96.3% |

補足:

- **① の GPOA は Novy-Marx (2013)、ACC は Sloan (1996)** で、QMJ はこれらを束ねた枠組みである。つまり①は「既存式の既存の束ね方」になる。
- **② は F-Score をそのまま使える。** 参考文献マスターは「原式9項目のうちデータ取得可能な6項目で実装」と注記しているが、PITパネルには9項目すべてが入っており(平均8.8/9項目が計算可)、**原式どおり9項目で実装できる**。注記の是正が必要。
- **④ に Greenblatt の益回りを足しても、B/M と E/P だけの版とほぼ同じ順位になる**(順位相関0.94〜0.96)。増やす必然性は薄い。

## 検討したが使えなかった既存式

| 式 | 出典 | 不可の理由 |
|---|---|---|
| Mohanram G-Score | Mohanram (2005) | 8項目のうち広告宣伝費が取得不可。R&D・設備投資は回復したので7/8まで可能だが、原式どおりにはならない |
| 無形資本 | Peters & Taylor (2017) | 販管費の内訳(SG&A構成)が必要。EDINETからは安定して取れない |
| 技術的破壊エクスポージャ(TSD) | Caskurlu, Hoberg & Phillips (2024) | 特許テキストのLLM埋め込みが必要。日本企業・手元データでは不可能 |
| 産業分類 TNIC | Hoberg & Phillips | 米国10-Kのテキスト類似度が前提。日本の有報には未整備 |
| マジックフォーミュラ単体 | Greenblatt (2005) | 実装は**可能**だが、4軸合成より予測力が劣った(§D) |

**「構造変化の恩恵を受けるか」を直接測る既存式は存在するが(TSD)、手元データでは実装できない。** 代替として研究開発集約度(CLS 2001)を当てるのが、実装可能な範囲では最も出典が確かな選択になる。

# C. 可能にしたのは抽出バグの是正

## C-1. 研究開発費は「無かった」のではなく「取れていなかった」

`src/data/parse_edinet_xbrl.py:43` のタグ候補:

```
"rd_expense": ["ResearchAndDevelopmentExpenses", "ResearchAndDevelopmentExpense"],
```

実ファイル25社をサンプリングして出現タグを数えたところ、実際に使われているのは:

```
ResearchAndDevelopmentExpensesSGA                              (販管費の内訳)
ResearchAndDevelopmentExpensesResearchAndDevelopmentActivities (研究開発活動の記載)
```

**接尾辞が違うため一度も一致していなかった。** 同じ理由で設備投資(`CapitalExpendituresOverviewOfCapitalExpendituresEtc`)も取れていなかった。

正しいタグで全提出10,712件を取り直した結果:

| 項目 | 修正前 | 修正後 |
|---|---|---|
| 研究開発費 | **0.1%** | **56.3%** (適格企業では65.0%) |
| 設備投資 | **4.4%** | **98.0%** |
| 減価償却費 | ― | 97.6% |
| 現預金 | ― | **100.0%** |
| 利益剰余金 | ― | **100.0%** |
| 有形固定資産 | ― | 98.5% |
| 有利子負債 | ― | 82.2% |

所要時間は全10,712件で約2分(正規表現による直接抽出)。

**`DATA_MISSINGNESS_AUDIT_v1.md` §B-5 の「研究開発費は3,649社中2社しかない」は誤りである。** データの不在ではなく、タグ名の取り違えによる抽出漏れだった。同監査が「離の無形資産項は機能していない」「守の競争優位は営業利益率の二重計上に退化している」と結論した根拠も、この一点に依存している。**両方とも撤回・再評価が必要。**

## C-2. 現預金・有利子負債が取れたことで企業価値(EV)が作れる

これで以下が新たに実装可能になった。

- **Greenblatt (2005) マジックフォーミュラ**: 益回り = EBIT / EV、資本利益率 = EBIT / (正味運転資本 + 正味固定資産)
- **Carlisle アクワイアラーズ・マルチプル**: EV / EBIT
- **Altman (1968) Z-Score**: 5成分すべて計算可(留保利益が取れたため)。カバレッジ96.3%

## D-4. QMJ が負に効いたことをどう扱うか

3コホートすべてが2023〜2026年の同じ相場に属する。この期間の日本株は東証のPBR改善要請を背景にした歴史的なバリュー・小型株優位局面であり、**高収益・大型の「クオリティ」が一貫して劣後した。**

STOCKリーグはリターンを採点しないので、**ここは「出典のある式を使い、その期間の結果を正直に書く」ほうが得点になる。**

# F. 残る自作部分 — 「式」と「しきい値」は別物

**式はすべて既存にできる。しかし数値パラメータは自作が残る。** ここは正直に分けて書くべきで、隠すと逆に弱い。

| 残る自作 | 内容 | 逃げ道 |
|---|---|---|
| 4軸に25%ずつ | 等重み | Greenblatt (2005) 自身が2軸を等重みで合算している。**「等重みは既存の作法」と書ける** |
| 同一業種2社まで | 分散ルール | Markowitz (1952) は分散の原理の典拠になるが、**「2社」という数字は自作** |
| 流動性 2,000万円/日 | Step 0 | Amihud (2002) は概念の典拠。**数値は自作** |
| PER 0〜120 / PBR 0〜20 | 外れ値除外 | **完全に自作** |
| 3期連続赤字などの除外 | Step 0 | Graham (1949) 防御的投資家基準に近いが一致はしない |
| Altman Z < 1.81 | ディストレス除外 | **Altman (1968) 原論文の値。ここは既存** |

**推奨する書き方**: 「評価の式はすべて既存の学術・実務の定義をそのまま用いた。式の重みや境界値のうち、我々が決めたのは次の5点である」と表で出す。**自作の範囲を先に限定して開示すれば、査読で『どこから来た式か』と問われる箇所がなくなる。**

# G. 推奨する構成

```
Step 0  Amihud (2002) 流動性 2,000万円/日
        Altman (1968) Z-Score < 1.81 を除外
        3期連続赤字・営業CFマイナス・財務データ欠測を除外
        PER・PBRが常識的範囲にあること

① Moat   Asness, Frazzini & Pedersen (2019) QMJ Profitability
         = z平均( GPOA, ROE, ROA, CFOA, GMAR, −ACC )
           GPOA は Novy-Marx (2013)、ACC は Sloan (1996)

② Change Piotroski (2000) F-Score 9項目の合計

③ Future Chan, Lakonishok & Sougiannis (2001) 研究開発集約度
         = 順位平均( R&D/時価総額, R&D/売上 )
           非開示は「研究開発をしていない」= 0

④ Price  順位平均( Basu (1977) E/P, Fama & French (1992) B/M )
         ※ Greenblatt (2005) の EBIT/EV は足しても結果がほぼ変わらないので任意
```

# H. 限界

1. **③ Future は「次善」である。** 「構造変化の恩恵を受けるか」を直接測る既存式(Caskurlu, Hoberg & Phillips 2024 の技術的破壊指標)は存在するが、特許テキストのLLM埋め込みが必要で手元データでは実装できない。研究開発集約度は**イノベーションへの投資量**を測る指標であって、**恩恵を受けるかどうか**ではない。この読み替えは開示する必要がある。
2. **検証は3コホート・単一レジーム。** すべて2023〜2026年のバリュー優位局面に属する。QMJ が負に効いたのはこの局面の性質である可能性が高く、独立な3つの証拠ではない。
3. **R&D非開示35%を0とする扱い。** 業種分布から妥当と判断したが、サービス業などで「研究開発はしているが有報に記載義務がない」ケースを0にしている可能性は残る。
4. **有利子負債のカバレッジは82.2%。** EBIT/EV を使う場合、残り18%は負債ゼロとみなしている。B/M と E/P だけなら100%なので、この問題を避けられる。
5. **生存者バイアス。** パネルは提出済みの有報から構築しているため上場廃止企業が抜けている。
