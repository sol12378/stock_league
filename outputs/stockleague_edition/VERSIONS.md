## 運用ルール(確定版は二度と編集しない)

1. 確定した版には `beyond_buffett_stockleague_{ver}.LOCKED` マーカーを置く。**ビルドはLOCKED版への上書きをエラーで拒否する**(build_contest.py内蔵ガード)。
2. 修正を始めるときは、まず `VERSION` ファイルを繰り上げる(例: `printf 'v3' > VERSION`)。以後のビルドは `_v3` ファイルを新規生成し、v2以前には触れない。
3. ビルド手順(2パス):
   ```
   printf 'v3' > VERSION                       # 版を繰り上げ
   .venv/bin/python scripts/build_contest.py                       # パス1
   soffice --headless --convert-to pdf --outdir . beyond_buffett_stockleague_v3.docx
   .venv/bin/python scripts/make_tocmap.py                         # 目次実測 → tocmap_v3.json
   .venv/bin/python scripts/build_contest.py --tocmap tocmap_v3.json   # パス2
   soffice --headless --convert-to pdf --outdir . beyond_buffett_stockleague_v3.docx
   mkdir -p rendered_v3 && pdftoppm -png -r 100 beyond_buffett_stockleague_v3.pdf rendered_v3/p
   ```
   ページ数が変わったら make_tocmap.py→パス2 を収束するまで繰り返す。
4. 検証(目視・機械チェック・数値照合)を終えて確定したら `SCORECARD_v3.md` を書き、`touch beyond_buffett_stockleague_v3.LOCKED`。この索引に1行追記する。
5. 本文の数値は直接書かない(data_real.json / phase5系の正典から自動転記)。図は `scripts/make_contest_figures.py`(印刷実寸スケール)で生成する。
