# /loop 用プロンプト(自己ペース動的モード。起動: `/loop このファイルの指示に従いv5改善ループの1イテレーションを実行`)

STOCKリーグ提出版v5を「実在のファイナンス研究者に査読を依頼でき、知見を頂戴できる」水準まで反復改善するループの1イテレーションを実行する。

**正典**: `outputs/stockleague_edition/V5_PLAN.md`(計画・裁定10件・ルーブリック・ゲート)と `EXPERT_AUDIT_v4.md`(v4監査所見32項目)。矛盾時はV5_PLAN.mdが優先。

**絶対規律**(違反はいかなる進捗でも無効):
- v4以前・LOCKEDファイル不可侵。生成・更新はv5系ファイルのみ。
- 数値手打ち禁止——本文の全数値はスクリプト出力(JSON/CSV)からの自動転記。
- 実装・正典データを読んでから書く(記述はコードの挙動と1対1対応)。
- 人間パート(取材記録・学んだこと・SDGs理由・表紙)は記入欄のまま。創作はblocking違反。
- 本編は30頁以内・全文字10pt以上。あふれる詳細は技術補遺へ逃がす。

**このイテレーションの手順**:
1. `V5_PROGRESS.md` を読む(無ければV5_PLAN.md §9のテンプレートから作成)。未完了項目を依存順(WP0→1→2→3→4→5→6→7→8)に1〜3個選ぶ。
2. 選んだ項目をV5_PLAN.md §3の受入基準まで実施する。
3. 本編・補遺をビルド(目次2パス)し、ハードゲートG1〜G8(V5_PLAN.md §4)の機械チェックを実行。FAILは即修正してから先へ進む。
4. **WP0〜5がすべて完了している場合は毎回**、V5_PLAN.md §7に従いペルソナ査読を行う: ファイナンス論の世界的権威——実証資産価格理論とバックテスト方法論(過学習・多重検定)の双方の第一人者で、日本株市場の制度実務にも通じた研究者——として本編と技術補遺を通読し、修正点・問題点・データと論理の飛躍・**少しでも引っかかる点**を遠慮なく全件 `V5_REVIEW_FINDINGS.md` に記録する(blocking/major/minor分類+タグ)。blocking・majorは即修正し、minorも原則このイテレーション内で修正する。続けて10軸ルーブリック(§4)で採点し、軸ごとの根拠1行つきで `V5_SCORECARD_ITER.md` に追記する。
5. **収束判定**(V5_PLAN.md §5): 全軸9.0以上+G1〜G10全PASS+ペルソナ査読で blocking=0・major=0・minor≤2+例示的長所3つ以上+「実在の研究者にこのまま見せてよい」=YES、が**2イテレーション連続**——すなわち世界的権威が読んで全てを理解でき、この研究の規律の完全性に感嘆する水準——に達したら: 確定手順(SCORECARD_v5.md→VERSIONS.md追記→本編・補遺のLOCKED→referee_briefing_v5.md最終化)を実行し、ScheduleWakeupを`stop: true`で呼んでループを終了する。
6. 未収束なら `V5_PROGRESS.md` を更新(完了・残・頁収支・次の先頭項目・既決指摘)し、60〜120秒後のwakeupを予約して終了する。同一項目が3イテレーション連続で未達なら、代替アプローチを台帳に記録してから切り替える。30イテレーションを超えたら中間報告を台帳に書き、基準を緩めずに人間の判断を仰ぐ。
