# 新4軸スクリーニングの実装仕様 v2

`NEW4AXIS_SPEC_v1.md` を実装して確定20社を出す過程で、**Price軸の作り方がv1のままでは誤り**だと判明した。v2はその1点を差し替えたもの。**Step 0・Moat・Change・Future・Step 2〜4 はv1から変更なし**なので、そちらはv1を参照すること。

実装: `work/new_4axis_screen/07_final_screen.py`(＋`08`〜`09c`)
結果: `outputs/stockleague_edition/screening_report_v1.docx` / `work/new_4axis_screen/out/final_top20.csv`

---

## 何が誤りだったか

v1は時価総額をこう作れと書いていた。

```
発行済株式数 N = XBRLの発行済株式総数 − 自己株式数（提出時点）
時価総額 M = N × 基準日終値
```

**株価と株数の基準日が揃っていない。** 株価系列(Yahoo)は株式分割を遡って調整済みなのに、XBRLの株式数は「その有価証券報告書を提出した時点」の値である。提出後に分割した会社は M が分割比率のぶん過小になり、**見かけ上いちばん割安**になってPrice軸の最上位に張り付く。

v1のまま回した結果、**上位20社のうち6社がこれだった**。実勢値と突き合わせて確認した例:

| 銘柄 | XBRL株数 | 実勢株数 | 倍率 | PBR(誤) | PBR(正) |
|---|---|---|---|---|---|
| 6648 かわでん | 4,192,000 | 16,015,485 | 3.82倍 | 0.3 | **3.58** |
| 3798 ＵＬＳグループ | 6,228,800 | 56,578,380 | 9.08倍 | 0.3 | **2.39** |
| 5729 日本精鉱 | 2,605,900 | 9,802,968 | 3.76倍 | 0.3 | **1.14** |
| 3443 川田テクノロジーズ | 17,474,210 | 51,277,958 | 2.93倍 | 0.2 | **0.74** |

### 試して駄目だった代替案

**XBRLが報告する1株当たり数値(EPS・BPS)÷株価を使う** — 株数に依存しないので一見よさそうだが、**同じ理由で解決しない**。EPS・BPSも提出時点の株数を分母にしているため、分割後の株価と割ると同じズレが出る。実装済みの抽出は `08_extract_per_share.py` に残してあり、突合用に使える(EPS 3,577社・BPS 3,579社を17秒で取得できる)。

**提出書類どうしの株数を比較して分割を検出する** — 提出「前」の分割しか捕まらない。問題は提出「後」の分割なので効かない。

**PBRが極端に低い会社を機械的に外す** — 誤検出が多い。9505 北陸電力は PBR 0.4 だが実勢も 0.43 で正しく、除外は間違いになる。

## v2のPrice軸

**株価と株数を同じ時点に揃える。** これが唯一の解。

```
発行済株式数 N = 実勢値（yfinance fast_info の shares）
株価 P        = 実勢値（同 lastPrice）
時価総額 M    = N × P

益回り  E/P = 当期純利益 / M      ← 純利益は各社最新の有価証券報告書
純資産倍率の逆数 B/M = 自己資本 / M

Price = mean( pctrank(E/P), pctrank(B/M) )
```

集計値(純利益・自己資本)を使うのは、1株当たり数値と違って**株数の基準に依存しない**ため。分子は有報、分母は実勢時価総額という組み合わせが、PER・PBRの標準的な定義そのものになる。

### 取得の実務

`09_fetch_shares.py`(並列10) → `09b_retry_shares.py`(並列3・指数バックオフ) の2段構え。`fast_info` は1社あたり約1.1秒だが、Yahooのレート制限に当たるので初回は 906/1,963 しか取れない。バックオフ付きの再取得で **1,948/1,963 = 99.2%** まで埋まる。

全社ぶんが取り切れない場合は `09c_fill_candidates.py` を使う。暫定スコア上位150社に絞って未取得ぶんだけ埋める。**分割ズレは時価総額を過小に見せる＝Price軸を押し上げる方向にしか働かない**ので、Price軸の高い側さえ潰せば選抜は安定する。

### 実測（適格1,963社）

| | 値 |
|---|---|
| 実勢株数を取得できた企業 | 1,948社(99.2%) |
| 報告書の値にフォールバック | 15社 |
| 提出後の分割を検出（実勢/XBRL ≥ 1.5倍） | **216社** |
| うち直近3か月以内の分割 | 23社 |
| 母集団のPER中央値 / PBR中央値 | 16.2倍 / 1.33倍 |
| PBR1倍割れの比率 | 31.0% |

株価も現在値に揃えたので、**基準日は「株価・時価総額 2026-08-17／財務 各社最新の有報／流動性・業種 2026-06-01」**となる。v1が想定した2026-04-30基準ではない。

## 残る限界（レポートに書くこと）

1. **PERは有報の通期純利益ベース。** 提出後に業績が変わった会社では直近12か月ベースと差が出る。実例: 7991 マミヤ・オーピーは有報ベース2.4倍に対し直近12か月ベースでは6.5倍。**上位に入った銘柄は直近四半期の利益動向を必ず確認する。**
2. **1単元40万円超の334社が構造的に選ばれない。** 資金量に依存する制約であり、大型株の一部が最初から候補外になる。
3. **実勢株数の取得は外部データに依存する。** 15社は取得できず報告書の値のまま。再現時は取得日で結果が変わりうる。
4. Future軸の性質(業種ダミーR²=0.994・無形資産項が機能していない)は v1 §Step1③ および `NEW4AXIS_AUDIT_v1.md` のとおり。**v2でも未解決。**
