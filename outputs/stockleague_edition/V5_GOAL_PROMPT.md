# /goal 用プロンプト(単一の自律実行。/goalが無い環境では通常プロンプトとして投入しても同一挙動)

【ゴール】`outputs/stockleague_edition/` のSTOCKリーグ提出版をv5として、「実在のファイナンス論の世界的権威に査読を依頼でき、知見を頂戴できる」水準まで完成させる。**完成の定義はV5_PLAN.md §5の収束条件**——10軸ルーブリック(§4)すべて9.0以上+ハードゲートG1〜G10全PASS+ペルソナ査読で blocking=0・major=0・minor≤2・例示的長所3つ以上・「実在の研究者に見せてよい」=YES を**2回連続**——であり、これを満たすまで 修正→ビルド→機械チェック→査読→採点 のサイクルを自分で回し続ける。**満たす前に完了を宣言してはならない。**

【正典】`V5_PLAN.md`(計画・先行決定事項10件・ルーブリック・ゲート・プロトコル)と `EXPERT_AUDIT_v4.md`(v4監査所見32項目)。矛盾時はV5_PLAN.mdが優先。

【手順】V5_PLAN.md §3の依存順で進める:
WP0 正典データの是正(TOPIX欠測補完→対TOPIX全数値の再計算、BH系列、有意性、318社への理由コード付与、図表Ⅱ-1の自動転記化、可能ならwalk-forward試行)
→ WP1〜4 本文修正(P0-a数値是正 → P0-b論理防御 → P1査読耐性 → P2完成度)
→ WP5 査読用技術補遺の新規作成(§A〜H)
→ WP6 査読×採点の収束ループ
→ WP7 確定手順(SCORECARD_v5→VERSIONS.md→LOCKED)
→ WP8 査読依頼パッケージ(referee_briefing_v5.md)。

【絶対規律】v4以前・LOCKED不可侵、生成はv5系のみ/数値手打ち禁止(全数値は正典JSON/CSVから自動転記)/実装・正典を読んでから書く/人間パート(取材・学んだこと等)は記入欄のまま創作しない/本編30頁以内・全文字10pt以上、詳細は技術補遺へ。違反はいかなるスコアでも無効。

【査読サイクル】各ビルド完了のたびに、**ファイナンス論の世界的権威**——実証資産価格理論とバックテスト方法論(過学習・多重検定)の双方の第一人者で、日本株市場の制度実務にも通じた研究者——として本編と技術補遺を通読査読し、修正点・問題点・データと論理の飛躍・**少しでも引っかかる点**をすべて `V5_REVIEW_FINDINGS.md` に記録して全件修正する(blocking/major即時、minorも原則同サイクル内)。指摘が尽きるだけでなく、その研究者が「例示的に優れている」と挙げられる点を3つ以上持ち、**読んで全てを理解でき、規律の完全性に感嘆し、実在の研究者にそのまま見せてよい**と2回連続で判定できるまで繰り返す。採点は毎回 `V5_SCORECARD_ITER.md` に追記(10軸+根拠1行)。

【頑健性】30分ごと、またはWP完了ごとに `V5_PROGRESS.md` へ進捗を必ず書く(文脈が要約されても台帳だけで再開できる粒度: 完了・残・頁収支・次の先頭項目・既決指摘)。同一項目が3回連続で未達なら代替アプローチを台帳に記録して切替。人間にしか決められない事項は保留リストへ隔離して先へ進む。30サイクル超過時は中間報告を台帳に書き、基準を緩めずに人間の判断を仰ぐ。
