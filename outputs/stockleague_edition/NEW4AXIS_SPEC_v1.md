# 新4軸スクリーニングの実装仕様 v1

> **【訂正あり】Price軸の作り方はこのv1のままでは誤り。** 提出後に株式分割した会社で時価総額が過小になり、上位20社の6社が誤判定された。差し替えは `NEW4AXIS_SPEC_v2.md` を参照。Step 0・Moat・Change・Future・Step 2〜4 はv1のままで正しい。

`NEW4AXIS_AUDIT_v1.md` の検証結果を反映した、実際に回せる形の定義。監査で見つかった3つの必須修正(E-1 Price修復 / E-2 Changeから株価倍率を外す / E-3 Future開示)を織り込み済み。

記号: `pctrank(x)` = 母集団内での百分位順位を0〜100点にしたもの(同値は平均順位)。欠測はゼロ埋めせず、平均から外す。

---

## 前提: 時価総額を作り直す

これを先にやらないと Price 軸が8.3%の会社にしか存在しない。

```
発行済株式数 N = XBRL の NumberOfIssuedSharesAsOfFiscalYearEnd
                 − TotalNumberOfSharesHeldTreasury
                 (= PITパネルの shares_outstanding_pti、各社の最新提出分)

時価総額 M = N × 基準日終値
```

**必須ガード**: `M / 純利益 < 3` または `M / 自己資本 < 0.3` の会社にフラグを立てる。
決算書の提出後に株式分割した会社は N が古いままで M が過小になり、「異常に割安」として最上位に張り付く。
ユニバース全体では4.0%(78社)だが、**ガードなしで上位20社を取ると40%(8社)がこれに該当した**。
フラグ企業は最終20社に残った時点で1社ずつ手で検算する。

カバレッジ実測: 163社(8.3%) → **1,963社(100%)**。yfinance実測がある163社との突合で株式数の中央値比 1.0048、±5%以内が83.4%。

## Step 0 — 投資できる会社に絞る

全上場3,649社に対し、以下を**すべて**満たすものを残す。

| # | 条件 | 出典 |
|---|---|---|
| 0-1 | 株価データが存在する(終値 > 0) | 株価 |
| 0-2 | 直近60営業日の平均売買代金 ≥ **2,000万円/日** | 株価 |
| 0-3 | 総資産・自己資本・ROEが揃っている(非金融は自己資本比率・営業利益・営業CFも) | EDINET |
| 0-4 | 3期連続の営業赤字でない | EDINET |
| 0-5 | 3期連続の経常赤字・純損失でない | EDINET |
| 0-6 | 3期連続の営業CFマイナスでない | EDINET |
| 0-7 | 自己資本比率が極端に低くない / 負債比率が過大でない | EDINET |
| 0-8 | ROE が −50%〜+80%、営業利益率が −50%〜+100% の範囲内 | EDINET |
| 0-9 | **PER が 0超120以下、PBR が 0超20以下**(修復した時価総額で**全社に**適用) | 修復M + EDINET |

**0-9 が変更点。** 現行実装ではこの検査がPER/PBRを持つ売買代金上位300社にしか当たっておらず、修復データで全社に当てると**18社が新たに該当する**(＝いまは検査すらされずに通過している)。

通過見込み: 約1,940社(現行1,963社 − 新規該当18社)

> 落ちる会社の内訳(現行実測、重複あり): 3期連続営業CFマイナス284社・財務データ欠測262社・3期連続営業赤字151社・レバレッジ過大73社・自己資本比率不足69社・収益性の外れ値70社。ユニークで597社。
> これは「儲かる会社を選ぶ」段ではなく「そもそも買えない/データが信用できない会社を落とす」段である。

## Step 1 — 4軸で評価する

### ① Moat — 現在の競争優位

```
GP/A         = 売上総利益 / 総資産
営業利益率    = 営業利益 / 売上高
ROA          = 純利益 / 総資産
営業CF率      = 営業CF / 売上高
自己資本比率  = 1 − 負債 / 総資産

Moat = mean( pctrank(GP/A), pctrank(営業利益率), pctrank(ROA),
             pctrank(営業CF率), pctrank(自己資本比率) )
```

現行の `moat_score` から変えた点: `rd_ratio`(研究開発費比率)を外した。**3,649社中2社しか値が無く**、ゼロ埋めの結果「競争優位」の枠が営業利益率の二重計上に退化していたため。代わりに Novy-Marx の GP/A を入れた。

カバレッジ実測: 90.5%〜100%。

### ② Change — 競争優位が改善しているか

```
Change = mean( pctrank(Piotroski F スコア),
               pctrank(ΔROA),
               pctrank(Δ売上総利益率),
               pctrank(Δ総資産回転率),
               pctrank(増収率),
               pctrank(営業増益率) )

  ΔX      = X(今期) − X(前期)
  増収率   = (売上高 − 前期売上高) / |前期売上高|
  営業増益率 = (営業利益 − 前期営業利益) / |前期営業利益|
```

Piotroski F スコアは以下9項目の合計(各0/1、0〜9点):
ROAがプラス / 営業CFがプラス / ROAが改善 / 営業CF > 純利益(会計品質) /
レバレッジが低下 / 流動比率が改善 / 増資していない / 売上総利益率が改善 / 総資産回転率が改善

**現行の `transformation_score` は使わない。** あの式は重みの70%がPBR・PER・配当利回りで、Price軸と二重計上になっていた(順位相関 +0.368)。上の定義なら株価倍率を一切含まず、Priceとの相関は **−0.094** まで下がる。

カバレッジ実測: Piotroski 100%(平均8.8/9項目)、ΔROA 99.9%、Δ売上総利益率 90.5%、Δ総資産回転率 96.8%。

### ③ Future — 構造変化の恩恵を受けられるか

```
Future_raw = 0.30·z(AI基盤エクスポージャ)
           + 0.25·z(無形資産投資)
           + 0.20·z(省人化エクスポージャ)
           + 0.15·z(データ・ソフトウェアエクスポージャ)
           + 0.10·z(信頼・安全エクスポージャ)

Future = pctrank(Future_raw)
```

各エクスポージャは EDINET 本文のキーワード照合(半導体・データセンター・ロボット・クラウド・セキュリティ等)。

**この軸には次の2点を必ず併記する。**

1. **無形資産投資(重み0.25)は事実上機能していない。** 研究開発費が3,649社中2社しか取れず、残りはゼロ埋め。実効はキーワード4本だけ。
2. **この軸は33業種ダミーへの回帰で R² = 0.994。** 1,963社が18通りの値しか取らず、45.3%(890社)が同一値。個社の判断ではなく、**構造変化の恩恵を受けやすい業種群に属しているかの判定**である。

### ④ Price — 高すぎないか

```
益回り E/P       = 純利益 / 時価総額 M
自己資本倍率 B/M  = 自己資本 / 時価総額 M

Price = mean( pctrank(E/P), pctrank(B/M) )
```

配当利回りは入れない(全社では取得できないため)。M は「前提」節で修復したもの。

## Step 2 — 合成する

```
総合点 = 0.25·Moat + 0.25·Change + 0.25·Future + 0.25·Price
```

**報告書には必ず実効寄与も併記する。** 名目25%は実効25%を意味しない。

| | Moat | Change | Future | Price |
|---|---|---|---|---|
| 名目 | 25% | 25% | 25% | 25% |
| 実効(分散寄与、修復後実測) | 24.1% | 29.2% | **32.1%** | **14.0%** |

Price が下がるのは、Price が他3軸と負の相関(Moat −0.217 / Change −0.094 / Future −0.142)を持ち、合計のなかで打ち消されるため。

### 代替案: Future を下げる

「業種ラベルに25%は重い」と考えるなら:

```
総合点 = 0.2833·Moat + 0.2833·Change + 0.15·Future + 0.2833·Price
```

前向き検証では Future を外した3軸が3コホートすべてで等重み4軸を上回った(rank IC 0.155/0.219/0.175 対 0.072/0.218/0.104)。ただし「未来」という物語を失うので、**0にはせず0.15に下げる**のが折衷案。

## Step 3 — 20社を選ぶ

```
1. 総合点の降順に並べる
2. 上から順に採用する。ただし同一の33業種分類は最大2社まで
3. 20社に達したら終了
```

**この業種上限は必須。** 外すと20社が4業種に集中する(機械11社・電気機器6社で17/20)。上限2社なら13業種に散る。代償は平均総合点で −4.9点。

---

## Step 4 — 保有比率を決める

```
均等ウェイト: 各銘柄 5.00%(= 1/20)
```

**均等を推奨する。** 総合点に比例させても実測で4.47%〜5.98%(最大/最小 1.34倍)にしかならず、既存の上限8%は一度も効かない。差が出ないなら説明しやすいほうがよい。

株数への落とし込み(投資枠500万円の場合):

```
1銘柄あたりの目標投資額 = 5,000,000 × 0.05 = 250,000円
株数 = floor( 250,000 / 基準日終値 / 売買単位 ) × 売買単位
余った現金 = 総合点の高い順に1単元ずつ追加購入(上限8%を超えない範囲で)
```

## 実行順序のまとめ

```
1. XBRLから発行済株式数を全社ぶん取り、基準日終値を掛けて時価総額 M を作る
2. M で PER / PBR を計算し、PER<3 or PBR<0.3 にフラグを立てる
3. Step 0 の9条件で約1,940社に絞る(0-9 は M を使う)
4. 4軸をそれぞれ0〜100の順位点にする(欠測成分は平均から外す。ゼロ埋め禁止)
5. 25%ずつ足して総合点を出す
6. 総合点の降順、同一業種2社まで、20社
7. フラグの立った銘柄が20社に入っていたら、その会社のPER/PBRを手で検算する
8. 均等5%で株数に落とす
```
