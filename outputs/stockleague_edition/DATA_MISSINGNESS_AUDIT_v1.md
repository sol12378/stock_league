# B. データ欠測が選抜を支配している

## B-1. 根本原因: 時価総額系データは「売買代金上位300社」しか取得していない

`fetch_yfinance.py` の取得処理:

```
liquid_tickers = latest.sort_values("avg_trading_value_60d", ascending=False)["ticker"]  # 売買代金の降順
fetch_quote_metrics(liquid_tickers, ..., limit=quote_metrics_limit)                      # 先頭から打ち切り
```

実測: `yfinance_metrics.csv` は **300行**。その300社の売買代金順位は **1位〜300位で完全一致**(検証済み)。**無作為欠測ではなく、規模で決定論的に切られている。**

これで欠ける指標: 時価総額・株式数・ＰＥＲ・ＰＢＲ・配当利回り・ＥＶ・ＥＢＩＴＤＡ・β。

カバレッジ(適格1,791社):

| 規模区分 | 社数 | 取得済 | 率 |
|---|---|---|---|
| TOPIX Core30 | 6 | 6 | **100%** |
| TOPIX Large70 | 24 | 24 | **100%** |
| TOPIX Mid400 | 255 | 86 | 33.7% |
| TOPIX Small 1 | 381 | 13 | 3.4% |
| TOPIX Small 2 | 533 | 2 | **0.4%** |
| 区分なし(グロース等) | 592 | 8 | 1.4% |
| **合計** | **1,791** | **139** | **7.8%** |

売買代金の五分位別カバレッジ: **Q1〜Q4 = 0.0%、Q5(最大) = 38.8%**。市場別: プライム11.3%・スタンダード1.8%・**グロース0.8%**。

→ **「割安さ」を測る全指標が、大型株にしか存在しない。**これは欠測ではなく設計上の打ち切りであり、`--quote-metrics-limit` を上げて再取得すれば解消できる(既定値は800だが実行は300で止まっている)。

## B-2. 欠測は「除外」ではなく「平均」として扱われる — スコアが静かに歪む

`scoring.py` の合成は、z化した後 `.fillna(0)` する。**0 は母集団平均を意味する**ので、データを持たない企業は「平均並み」として残る。除外もされず、警告も出ない。

適格1,791社で**厳密に0**になっている成分:

| 成分 | 0の割合 | 使われ方 |
|---|---|---|
| `valuation_score` | **92.24%** (1,652社) | `bb_score` の重み0.15 → `adjusted_bb_score` → **破5・分散2の並べ替えキー** |
| `transformation_component_valuation_gap` | **92.24%** | 変わる堀の割安ギャップ |
| `future_moat_component_intangible_asset` | **99.89%** | 生まれる堀の重み0.25(**v11開示済**) |

`valuation_score` は取得済139社では0%が0、未取得1,652社では**100%が0**。つまり「割安さ」という軸は**大型株だけに存在する軸**として合成点に入っている。

帰結(上位k社のうち時価総額データを持つ企業の割合、母集団比率は7.8%):

| スコア | Top5 | Top10 | Top20 | Top50 |
|---|---|---|---|---|
| `valuation_score` | **100%** | **100%** | **100%** | **100%** |
| `transformation_score` | **100%** | 80% | 80% | 50% |
| `bb_score` | 80% | 60% | 50% | 24% |
| `adjusted_bb_score` | 60% | 40% | 50% | 30% |
| `moat_score`(参考) | 20% | 10% | 15% | 22% |
| `future_moat_score`(参考) | 20% | 40% | 25% | 16% |

## B-3. 破(変わる堀)は「データがある会社の中の順位」でしかない

実装の `transformation_score`(`scoring.py:640-646`):

```
transformation_score = 0.35·z(1/PBR) + 0.20·z(1/PER) + 0.20·avg_z(増収,増益) + 0.15·z(配当利回り)
```

- **重みの合計が0.90**(1.00でない。それ自体が実装の不整合)
- うち **0.70(=全体の78%)が時価総額系フィールド**。取得できていない1,652社では、その3項が**すべて厳密に0**になり、スコアは実質 `0.20×成長zスコア` だけになる。

分散の実測:

| | 社数 | 標準偏差 | 最大値 |
|---|---|---|---|
| 時価総額データあり | 139 | **0.516** | **2.040** |
| なし | 1,652 | 0.140 | 0.937 |

**分散が3.7倍違う。**同じスコアに見えて、2種類の別の式が混在している。だから上位は取得済企業で埋まる(Top5=100%)。

**反実仮想**: 全社で計算できる成長項だけで `変わる堀` を作り直すと、破5は——

| | 5社 |
|---|---|
| 現行 | 9022 JR東海 / 9513 J-POWER / 9503 関西電力 / 1662 石油資源開発 / 5214 日本電気硝子 |
| 欠測フィールドを外す | 4784 GMOインターネット / 4418 JDSC / 6016 ジャパンエンジン / 5034 unerry / 9338 INFORICH |
| **重複** | **0社** |

**破5は1社も残らない。**「変わる堀の5社」は、変革の度合いではなく**時価総額データの在庫**で決まっていた、というのが実測の結論である。

## B-4. 守5の割安順位は、162社中142社をデータ欠測だけで落としている

守の最終段は Greenblatt 方式(ＲＯＥ順位＋益回り順位)で、益回り = 純利益 ÷ 時価総額。時価総額がなければ順位を付けられない。

| | 実測 |
|---|---|
| 品質ゲート通過 | 162社 |
| うち時価総額データあり(＝守5の候補) | **20社** |
| データ欠測だけで候補から外れた | **142社(87.7%)** |
| 外れた142社のＲＯＥ中央値 | **19.6%** |
| 残った20社のＲＯＥ中央値 | 23.3% |
| 外れた142社の売買代金中央値 | **2.1億円** |
| 残った20社の売買代金中央値 | **115.1億円(54倍)** |

**落ちた142社は品質が劣るのではない**(ＲＯＥ中央値19.6% 対 23.3%)。**売買代金が小さいだけ**である。したがって「適格1,791社→品質162社→守5」という物語は、実質**「20社から5社」**である。

なお守の品質ゲート自体(ＲＯＥ・利益率・自己資本比率・無赤字・営業ＣＦ・増収増益)はＥＤＩＮＥＴ財務だけで動くため頑健で、適格母集団での欠測は `operating_income_growth` の24社のみ。反実仮想として**ＲＯＥ順位のみで守5を選ぶと3/5が一致**する(新規に 5032 ＡＮＹＣＯＬＯＲ・4776 サイボウズが入る)。守の欠陥は**ゲートではなく最後の割安順位**に局在している。

## B-5. 研究開発費の欠測が、離だけでなく守も汚染している(v11未開示)

`rd_expense` は **3,649社中2社**しか値がない(`capex` は**0社**＝完全に空)。v11は生まれる堀の無形資産項(重み0.25)についてこれを正しく開示している。**しかし同じ欠測が守の `moat_score` にも入っている:**

```
competitive_position_score = average_z(df, ["rd_ratio", "operating_margin"])
```

`rd_ratio` が実質全社欠測でゼロ埋めされるため、この成分は **0.5 × z(営業利益率)** に退化する。実測で確認:

- 比 `competitive_position_score / z(営業利益率)` の**中央値 = 0.500**(ぴったり)
- 相関 = **0.9191**

営業利益率は `profitability_score`(重み0.35)にも入っているので、`moat_score` の実効重みはこうなる:

| 実質的に測っているもの | 実効重み |
|---|---|
| **営業利益率** | **0.217**(＝0.35/3 ＋ 0.20×0.5) |
| 営業ＣＦ率 | 0.250 |
| 低ボラティリティ | 0.200 |
| ＲＯＥ | 0.117 |
| 自己資本比率 | 0.117 |

**「堀の4本柱(収益性・現金創出・安定性・競争優位)」は実質3本柱**であり、競争優位の枠は営業利益率の二重計上になっている。ＲＯＥの実効重みは営業利益率の**半分**。本文が説明する堀の構造と、実際に測っている構造が違う。

## 補足: 何が壊れていないか

公平のために書く。

- **守の品質ゲート**は ＥＤＩＮＥＴ財務のみで動き、適格母集団での欠測はほぼゼロ。ＲＯＥ順位のみに変えても3/5一致する。**堀の品質判定そのものは頑健。**
- **離**については、v11が「キーワード照合・業種ダミー・研究開発費のゼロ埋め」を全上場3,649社で検算して開示済み。**この層は正しく処理されている**——むしろv11が到達した水準を、守と破にも同じだけ適用すればよい。
- **A-3の流動性しきい値と C-1〜C-5 は最終20社を変えない。**開示の誤りであって結果の誤りではない。
- 本監査は選定ロジックの検査であり、リターン(STOCKリーグでは採点対象外)の主張には触れていない。
